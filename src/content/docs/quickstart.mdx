本指南将带你完成 Warp 的安装、体验每天都会用到的终端功能，并发送第一条 Agent 提示。完成本指南中的步骤后，你将拥有一个可正常运行的 Warp 环境，并对终端命令与 Agent 如何协同工作有清晰的了解。

## 前提条件

* **macOS、Windows 或 Linux** - 各平台的最低要求请参见[安装与设置](/getting-started/quickstart/installation-and-setup/)。

---

## 1. 安装 Warp

从 [warp.dev](https://www.warp.dev/download) 下载 Warp，并按照适用于你平台的安装程序进行操作。

<Tabs>
  <TabItem label="macOS">
    下载 Warp 并将其拖入 Applications 文件夹，或使用 Homebrew 安装：

    ```bash
    brew install --cask warp
    ```
  </TabItem>
  <TabItem label="Windows">
    下载并运行安装程序，或使用 WinGet 安装：

    ```powershell
    winget install Warp.Warp
    ```
  </TabItem>
  <TabItem label="Linux">
    从 [warp.dev/download](https://www.warp.dev/download) 下载适用于你发行版的软件包。Debian/Ubuntu 系统：

    ```bash
    sudo apt install ./warp-terminal.deb
    ```

    所有 Linux 安装选项请参见[安装与设置](/getting-started/quickstart/installation-and-setup/)。
  </TabItem>
</Tabs>

启动 Warp 后，你将看到一个准备好接受输入的终端会话。你可以选择注册账号（右上角），也可以跳过并立即开始使用 Warp。

## 2. 执行命令，感受 Blocks

执行任何你平时会用到的命令，例如：

```bash
ls -la
```

你会注意到输出与传统终端有所不同。每条命令及其输出都被组织成一个 **Block**——一个可独立复制、搜索、过滤和导航的独立单元。Block 是 Warp 组织终端内容的基础。

**Block 的使用方式：**

* 点击 Block 将其选中，然后按 `⌘C`（macOS）或 `Ctrl+Shift+C`（Windows/Linux）复制输出内容
* 使用 `⌘↑`/`⌘↓`（macOS）或 `Ctrl+↑`/`Ctrl+↓`（Windows/Linux）在 Block 之间导航
* 点击 Block 上的筛选图标，在其输出内容中搜索

更多关于导航、选择和操作输出的内容，请参见 [Block 基础](/terminal/blocks/block-basics/)。

## 3. 体验输入编辑器

Warp 的输入框不是普通的终端提示符，而是一个真正的文本编辑器。试试以下功能：

* **多行编辑** - 按 `Shift+Enter` 换行。尝试输入三行 `echo` 命令，每行之间按 `Shift+Enter`，最后按 `Enter` 一次性运行所有命令。
* **点击定位光标** - 像文本编辑器一样，点击输入框中的任意位置即可移动光标。
* **选择并编辑** - 点击并拖动以选中文本，然后直接输入替换内容。

三条命令依次执行，每条命令都会生成各自的 Block，无需逐条运行。

更多关于光标移动、选择和多行输入的内容，请参见[现代文本编辑](/terminal/editor/)。

## 4. 体验自动建议与补全

开始输入你之前执行过的命令。系统会根据 Shell 历史记录，以淡色文字的形式在行内显示建议。按 `→` 键即可立即接受。

输入时按 `Tab` 键可查看命令、参数和文件路径的补全选项。Warp 提供的补全功能超越了 Shell 原生的补全能力。

如果你输错了命令，Warp 会检测到错误并建议更正。接受修复或忽略并继续即可。

了解更多：[自动建议](/terminal/command-completions/autosuggestions/)和 [Tab 补全](/terminal/command-completions/completions/)。

## 5. 提出第一个 Agent 问题

目前为止你所做的一切都是在**终端模式**下运行 Shell 命令，与平时的使用方式一样。Warp 还提供 **Agent Mode**——一个专门的对话视图，你可以在其中用自然语言与 Warp 内置 Agent Oz 交互。

按 `⌘↩`（macOS）或 `Ctrl+Shift+Enter`（Windows/Linux）开始一次 Agent 对话，然后输入提示：

```
Explain the architecture of this project
```

Oz 会读取你的代码库，理解其结构，并给出具有上下文感知能力的解释。此后你可以继续追问、让 Oz 编写或重构代码、调试错误，或代你执行命令——一切都在同一个对话中完成。

:::note
你并非总需要手动切换模式。如果你在终端模式下输入自然语言提示，Warp 会自动检测并提示是否发送给 Agent。
:::

Warp 还支持与 Claude Code、Codex 等第三方 CLI Agent 配合使用。了解更多：[第三方 CLI Agent](/agent-platform/cli-agents/overview/)。

关于模式切换的更多内容，请参见 [Terminal and Agent modes](/agent-platform/local-agents/interacting-with-agents/terminal-and-agent-modes/)。

## 接下来探索什么

掌握基础之后，来了解让 Warp 成为完整开发环境的功能：

* **[自定义 Warp](/getting-started/quickstart/customizing-warp/)** — 选择主题、配置提示符、选择 AI 模型，并从其他终端导入快捷键绑定。
* **[Codebase Context](/agent-platform/capabilities/codebase-context/)** — 索引你的 Git 仓库，让 Agent 理解你的代码，并在大型多仓库系统中提供具有上下文感知的回答。
* **[Oz 云 Agent](/agent-platform/cloud-agents/overview/)** — 在后台运行 Agent，用于 PR 审查、议题分类、依赖更新等无需立即关注的任务。
* **[键盘快捷键](/getting-started/keyboard-shortcuts/)** — 面向高级用户的完整快捷键参考。
