Warp 启动时会显示一个快捷键界面，展示部分最常用的键盘快捷键。点击 x 按钮可隐藏该界面。你也可以通过 [Command Palette](/terminal/command-palette/) 或资源中心的快捷键侧边栏快速查看键盘快捷键。

## 自定义键盘快捷键

前往 **Settings** > **Keyboard shortcuts** 可设置自定义快捷键、清除快捷键或恢复默认快捷键。使用搜索栏可以搜索可重新映射的操作或现有快捷键。

也可以通过文件重新映射键盘快捷键。详见我们的 [keysets 代码仓库](https://github.com/warpdotdev/keysets/tree/main)。

:::note
在 macOS 上，[系统键盘快捷键](https://support.apple.com/en-us/HT201236)（如 `CMD-ESC`、`CMD-BACKTICK`、`CMD-TAB`、`CMD-PERIOD` 和 `CMD-TILDE`）需要先[解除绑定](https://support.apple.com/guide/mac-help/keyboard-shortcuts-mchlp2262/mac)，才能在 Warp 中使用。
:::

:::caution
与其他快捷键冲突的绑定会以橙色边框高亮显示。
:::
