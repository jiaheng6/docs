## Warp 默认 Shell

Warp 默认尝试加载你的登录 Shell。目前，Warp 支持 bash、fish、zsh 和 PowerShell（pwsh）。如果你的登录 Shell 设置为其他类型（例如 Nushell），Warp 将显示一条提示横幅说明不支持该 Shell，并加载以下默认 Shell：

* 在 macOS 上，默认 Shell 为 zsh。
* 在 Windows 上，默认 Shell 为 PowerShell（pwsh）。
* 在 Linux 上，默认 Shell 为 bash。

:::note
如果你在配置 RC 文件（`~/.bashrc`、`~/.zshrc`、`config.fish`、`Microsoft.PowerShell_profile.ps1`）时遇到问题，请参见[配置和调试 RC 文件](/support-and-community/troubleshooting-and-support/known-issues/#configuring-and-debugging-your-rc-files)。
:::

### 更改 Warp 使用的 Shell

要更改默认 Shell，建议在 Warp 中进行设置：前往 **Settings** > **Features**，向下滚动到 `Session` 部分，然后选择"Startup shell for new sessions"。

:::note
更改 Shell 设置后，只有在开启新会话时才会生效。
:::

## 自定义 Shell 环境

### 自定义 zsh Shell 环境

zsh 可通过 `~/.zshrc` 文件进行自定义，该文件会在每次新会话启动时（窗口、标签页或面板）运行。可用它设置环境变量、别名，以及自定义[提示符](/terminal/appearance/prompt/)。

#### 编辑 .zshrc 文件

使用 `nano ~/.zshrc` 或 `vi ~/.zshrc` 编辑 `~/.zshrc`。

:::note
以点（`.`）开头的文件默认是隐藏的。请检查文件管理器的设置，以显示隐藏文件。
:::

#### 重新加载 zshrc 文件

运行 `source ~/.zshrc` 或重启 Warp/打开新会话以应用更改。

### 自定义 Bash Shell 环境

Bash 预装于 macOS，可通过 `~/.bashrc`（非登录 Shell）或 `~/.bash_profile`（登录 Shell）进行自定义。使用这些文件设置环境变量、别名，以及自定义[提示符](/terminal/appearance/prompt/)。

#### 编辑 .bashrc 文件

使用 `nano ~/.bashrc` 或 `vi ~/.bashrc` 编辑 `~/.bashrc`。

#### 重新加载 bashrc 文件

运行 `source ~/.bashrc` 或重启 Warp/打开新会话以应用更改。

:::note
以点（`.`）开头的文件默认是隐藏的。请检查文件管理器的设置，以显示隐藏文件。
:::

### 自定义 Fish Shell 环境

Fish 是一款用户友好的 Shell，内置自动建议和语法高亮。其配置文件位于 `~/.config/fish/config.fish`。

#### 编辑 config.fish 文件

使用 `nano ~/.config/fish` 编辑 `~/.config/fish/config.fish`，可用它设置环境变量、别名和函数。

#### 重新加载 config.fish 文件

运行 `source ~/.config/fish` 或重启 Warp/打开新会话以应用更改。

:::note
与 Bash 和 Zsh 不同，Fish 不使用 `export VAR=value`。对于持久性环境变量，请使用 `set -Ux VAR value`。
:::

### 自定义 PowerShell Shell 环境

PowerShell 可通过其配置脚本进行自定义，该脚本位于 `$PROFILE`。使用 `Test-Path $PROFILE` 检查是否存在，如不存在可用 `New-Item -Path $PROFILE -ItemType File -Force` 创建。

#### 编辑 PowerShell 配置文件

使用 `code $PROFILE` 编辑配置文件，可用它设置环境变量、别名、自定义提示符和脚本。

#### 重新加载 PowerShell 配置文件

重启 Warp 或打开新会话以应用更改。

:::note
PowerShell 的执行策略可能会阻止脚本运行。使用以下命令启用配置文件执行：

```powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
```
:::

## macOS 上的额外 Shell 使用指南

#### 在 Warp 中设置 zsh

默认情况下，macOS 预装了 [zsh](https://zsh.sourceforge.io/Doc/Release/zsh_toc.html)，位于 `/bin/zsh`。你可以在 Warp 中输入 `which zsh` 确认该路径。也可以通过以下命令查看系统安装的 zsh 版本：

`$ zsh --version`

### 在 macOS 上的 Warp 中使用 fish shell

#### 第一步：安装 fish

虽然 macOS 系统预装了 bash 和 zsh，但 fish shell 并未预装。因此，在 Warp 中使用 fish 之前，需要先安装它。请使用以下方法之一安装 fish 3.6 或更高版本：

1. 通过 Homebrew：如果你已安装 Homebrew，只需在终端输入 `brew install fish`，并按照提示操作即可。
2. 从 [fishshell.com](https://fishshell.com/) 下载安装程序

#### 第二步：将 fish 设为默认 Shell

安装完成后，你可以将 fish 设为默认 Shell，这样每次 Warp 开启新标签页、面板或窗口时都会使用 fish。你可以仅在 Warp 的会话设置中（**Settings** > **Features** > **Session**）将 fish 设为 Warp 的默认 Shell，也可以将其设为用户账户的默认 Shell。要更改账户默认 Shell，需要运行两条命令。

**如果你在 macOS 上通过 Homebrew 安装了 fish，或通过 fishshell.com 上提供的 macOS 安装程序安装了 fish**，请在 Warp 中输入以下两条命令：

```
echo $(which fish) | sudo tee -a /etc/shells
chsh -s $(which fish)
```

:::note
如果你愿意，也可以使用你喜欢的编辑器手动编辑 `/etc/shells` 文件（可能需要 sudo 权限）。
:::

:::note
**为什么安装位置不同？** fish 的位置取决于安装方式。Homebrew 在搭载 Intel 处理器的 macOS 上将程序安装在 `/usr/local` 下，但在搭载 Apple Silicon 的 macOS 上则安装在 `/opt/homebrew` 下。因此，如果你在搭载 Apple Silicon 的 macOS 上通过 Homebrew 安装了 fish，其可执行文件路径为 `/opt/homebrew/bin/fish`。\
你可以通过运行 `which fish` 来确认 fish 的安装位置。
:::

### 在 macOS 上的 Warp 中使用 PowerShell（pwsh）

#### 第一步：安装 PowerShell

虽然 macOS 系统预装了 bash 和 zsh，但 PowerShell 并未预装。因此，在 Warp 中使用 PowerShell 之前，需要先安装它。请使用以下方法之一安装 PowerShell 7.0 或更高版本：

1. 通过 Homebrew：如果你已安装 Homebrew，只需输入 `brew install powershell/tap/powershell`，并按照提示操作即可。
2. 从 [Microsoft 官方网站](https://learn.microsoft.com/en-us/powershell/scripting/install/installing-powershell)下载

#### 第二步：将 pwsh 设为默认 Shell

安装完成后，你可以将 PowerShell 设为默认 Shell，这样每次 Warp 开启新标签页、面板或窗口时都会使用它。你可以仅在 Warp 的会话设置中（**Settings** > **Features** > **Session**）将 pwsh 设为 Warp 的默认 Shell，也可以将其设为用户账户的默认 Shell。要更改账户默认 Shell，需要运行两条命令。

```
echo $(which pwsh) | sudo tee -a /etc/shells
chsh -s $(which pwsh)
```

:::note
如果你愿意，也可以使用你喜欢的编辑器手动编辑 `/etc/shells` 文件（可能需要 sudo 权限）。
:::

:::note
**为什么安装位置不同？** pwsh 的位置取决于安装方式。Homebrew 在搭载 Intel 处理器的 macOS 上将程序安装在 `/usr/local` 下，但在搭载 Apple Silicon 的 macOS 上则安装在 `/opt/homebrew` 下。因此，如果你在搭载 Apple Silicon 的 macOS 上通过 Homebrew 安装了 pwsh，其可执行文件路径为 `/opt/homebrew/bin/pwsh`。
你可以通过运行 `which pwsh` 来确认 pwsh 的安装位置。
:::

## 在 Windows 上使用 Warp 中的 Shell

在 Windows 上，Warp 的默认 Shell 为 PowerShell 7（pwsh）。Windows 版 Warp 支持以下几种 Shell：

* PowerShell 7（默认）
* PowerShell 5
* Windows Subsystem for Linux（WSL2）
* Git Bash

:::note
目前不支持 Windows 命令提示符（cmd.exe）。有关 cmd.exe 支持的更多信息和进展，请参见[此 GitHub issue](https://github.com/warpdotdev/Warp/issues/5882)。
:::
