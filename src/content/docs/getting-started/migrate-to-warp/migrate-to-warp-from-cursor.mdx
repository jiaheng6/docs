Warp 为 Cursor 用户提供了两条清晰的迁移路径：保留 Cursor 作为编辑器，用 Warp 处理终端和 Agent 工作；或者完全迁移到 Warp 内置的代码编辑器和 Agent Mode。本页将介绍这两种方案。

## 可自动迁移的内容

Warp 不提供 Cursor 导入器。Cursor 基于 VS Code 代码库构建，其终端设置保存在 `settings.json` 中，对应键名如 `terminal.integrated.fontFamily` 和 `terminal.integrated.defaultProfile.*`。在重新配置 Warp 时，可通过 **Command Palette** > **Preferences: Open User Settings (JSON)** 打开用户设置作为参考。

## 使用 Warp 的 Agent 迁移设置（推荐）

迁移 Cursor 终端配置最快的方式，是让 Warp 的 Agent 直接翻译你的 `settings.json`。Warp 提供了一个 [`settings.toml` 文件](/terminal/settings/)和内置的 `modify-settings` 技能，让 Agent 可以读取你的现有配置，并将等效设置写入 Warp 的配置文件中。

1. 在 Warp 中打开新标签页，按 `⌘+I`（macOS）或 `Ctrl+I`（Linux/Windows）切换到 [Agent Mode](/agent-platform/local-agents/overview/)。
2. 粘贴如下提示词：

   > 读取我的 Cursor `settings.json`（macOS 路径：`~/Library/Application Support/Cursor/User/settings.json`），使用 `modify-settings` 技能将等效的终端设置（字体、光标样式、默认配置文件）迁移到我的 Warp `settings.toml` 中。应用前请显示差异对比。

3. 检查建议的差异并确认。Warp 会热重载 `settings.toml`，更改立即生效。

如果你更倾向于通过设置界面手动配置每项设置，以下步骤涵盖最常见的情况。

## 需要手动重新配置的内容

### 终端设置

Cursor 中的终端设置与 VS Code 使用相同的 Schema。迁移步骤与 VS Code 终端迁移完全相同——Shell、字体、主题和快捷键绑定的分步指南，请参见[从 VS Code 终端迁移到 Warp](/getting-started/migrate-to-warp/migrate-to-warp-from-vs-code-terminal/)。

### Agent 和 AI 设置

Cursor 的 Composer 和 Agent 功能没有一一对应的迁移路径——它们映射到不同的 Warp 概念。

* Cursor 中的 **Composer / Agent** 对应 Warp 的 [Agent Mode](/agent-platform/local-agents/overview/)。在任意标签页中开始 Agent 对话即可。
* **规则文件**（`.cursorrules`）——Warp 使用存储在 Warp Drive 中或以 `AGENTS.md`（或 `WARP.md`）提交到仓库的 [Rules](/agent-platform/capabilities/rules/)。在 Agent Mode 中运行 `/init` 可生成 `AGENTS.md`，或直接复制 `.cursorrules` 的内容。
* **MCP 服务器**——Warp 原生支持 MCP。配置方法详见 [MCP](/agent-platform/capabilities/mcp/)。

### 模型选择

Cursor 支持按对话选择模型。Warp 同样支持——在任意 Agent 对话中使用模型选择器即可。详见[模型选择](/agent-platform/capabilities/model-choice/)。

### 快捷键绑定

Warp 的[键盘快捷键](/getting-started/keyboard-shortcuts/)与 Cursor 有所不同。最值得注意的是，`⌘+I`（或 Linux/Windows 上的 `Ctrl+I`）用于在终端模式和 Agent Mode 之间切换。在终端模式下，也可以按 `⌘+Enter`（或 `Ctrl+Shift+Enter`）作为进入 Agent Mode 的另一种快捷键。

## 选择你的设置方案

### 将 Warp 与 Cursor 搭配使用

保留 Cursor 作为编辑器以获得更精准的文件内 AI 辅助，同时将 Warp 作为终端，用于：

* 长时间运行的命令和 SSH。
* 执行命令（而非仅编辑文件）的 [Agent Mode](/agent-platform/local-agents/overview/) 对话。
* 管理差异的 [Code Review](/code/code-review/)。
* 团队知识共享的 [Warp Drive](/knowledge-and-collaboration/warp-drive/)。

### 用 Warp 替代 Cursor

Warp 内置的[代码编辑器](/code/code-editor/)支持语言服务器协议（LSP）、[文件树](/code/code-editor/file-tree/)、[查找与替换](/code/code-editor/find-and-replace/)以及 [Vim 键盘绑定](/code/code-editor/code-editor-vim-keybindings/)。结合 Agent Mode、Code Review 和 Warp Drive，无需单独编辑器即可在 Warp 中完成完整的 Cursor 工作流。

## Warp 原生等效功能

Cursor 功能及其在 Warp 中的对应项：

| Cursor 中 | Warp 中 |
| --- | --- |
| Composer / Agent 面板 | 任意标签页中的 [Agent Mode](/agent-platform/local-agents/overview/)（按 `⌘+I` 切换） |
| Agent 标签页 | 跨标签页[并行运行多个 Agent](/agent-platform/local-agents/overview/) |
| `.cursorrules` | 项目根目录的 `AGENTS.md` / `WARP.md`，作为 [Rule](/agent-platform/capabilities/rules/) 被自动识别 |
| MCP 服务器 | [MCP](/agent-platform/capabilities/mcp/) |
| 按对话选择模型 | [模型选择器](/agent-platform/capabilities/model-choice/) |
| 代码库索引 | [Codebase Context](/agent-platform/capabilities/codebase-context/) |
| 内联差异审查 | [Code Review](/code/code-review/) |

开发工作流的概览，请参见[在 Warp 中编写代码](/getting-started/quickstart/coding-in-warp/)。
