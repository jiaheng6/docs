Warp 让 VS Code 用户可以自主选择迁移路径：保留 VS Code 用于编辑，将 Warp 作为终端与之搭配使用；或者用 Warp 内置的代码编辑器完全替代两者。本页介绍如何针对这两种路径重新配置终端设置。

## 可自动迁移的内容

Warp 不提供 VS Code 导入器——它是一个独立应用，不是 VS Code 扩展——但可以通过 Agent 代为完成大部分工作。你的 VS Code 终端设置保存在用户 `settings.json` 中，对应键名如下：

```json
"terminal.integrated.defaultProfile.osx": "zsh",
"terminal.integrated.fontFamily": "MesloLGS NF",
"terminal.integrated.fontSize": 14,
"terminal.integrated.cursorStyle": "line",
"terminal.integrated.profiles.osx": { ... }
```

## 使用 Warp 的 Agent 迁移设置（推荐）

迁移 VS Code 终端配置最快的方式，是让 Warp 的 Agent 直接翻译 `settings.json`。Warp 提供了一个 [`settings.toml` 文件](/terminal/settings/)和内置的 `modify-settings` 技能，让 Agent 可以读取你的现有配置，并将等效设置写入 Warp 的配置文件。

1. 在 Warp 中打开新标签页，按 `⌘+I`（macOS）或 `Ctrl+I`（Linux/Windows）切换到 [Agent Mode](/agent-platform/local-agents/overview/)。
2. 粘贴如下提示词：

   > 读取我的 VS Code `settings.json`（macOS 路径：`~/Library/Application Support/Code/User/settings.json`），使用 `modify-settings` 技能将等效的终端设置（`terminal.integrated.*` 键）迁移到我的 Warp `settings.toml` 中。应用前请显示差异对比。

3. 检查建议的差异并确认。Warp 会热重载 `settings.toml`。

如果你更倾向于通过设置界面手动配置每项设置，以下步骤涵盖最常见的情况。

## 需要手动重新配置的内容

### Shell

Warp 会自动检测你的登录 Shell。如需覆盖——例如匹配 `terminal.integrated.defaultProfile.*`——前往 **Settings** > **Features** > **Session**，在 **Startup shell for new sessions** 中选择 Shell。

### 字体和光标

在 Warp 的 **Settings** > **Appearance** > **Text, fonts, & cursor** 中，设置字体系列和大小以匹配 `terminal.integrated.fontFamily` 和 `terminal.integrated.fontSize`。

### 主题

VS Code 的终端使用整体编辑器主题的配色方案。在 Warp 中，从 **Settings** > **Appearance** > **Themes** 选择相近的主题，或[创建自定义主题](/terminal/appearance/custom-themes/)以匹配 VS Code 主题的 `terminal.*` 颜色标记。

### 快捷键绑定

Warp 的[默认键盘快捷键](/getting-started/keyboard-shortcuts/)与 VS Code 终端快捷键（分割面板、新标签页、查找）基本一致。对于你在 VS Code 中配置的自定义绑定，在 Warp 的 **Settings** > **Keyboard shortcuts** 中添加。

## 选择你的设置方案

### 将 Warp 与 VS Code 搭配使用

许多开发者保留 VS Code 作为编辑器，将 Warp 作为终端，在需要长时间运行命令、SSH 会话或 AI 辅助工作流时切换使用。无需更改 VS Code——只需安装 Warp，需要时打开即可。

VS Code 的集成终端仍然可用；用它处理快速的一次性命令，需要 [Block](/terminal/blocks/)、[Agent Mode](/agent-platform/local-agents/overview/) 或[持久会话](/terminal/sessions/session-restoration/)时，切换到 Warp。

### 用 Warp 替代 VS Code

Warp 内置了[代码编辑器](/code/code-editor/)，支持语言服务器协议（LSP）、[文件树](/code/code-editor/file-tree/)、[查找与替换](/code/code-editor/find-and-replace/)以及 [Vim 键盘绑定](/code/code-editor/code-editor-vim-keybindings/)。结合 [Code Review](/code/code-review/)，许多开发者将 Warp 作为主要编辑器，完全抛弃了 VS Code。

从命令行使用 `warp .` 打开目录即可开始编辑。

## Warp 原生等效功能

VS Code 终端功能及其在 Warp 中的等效项：

| VS Code 终端中 | Warp 中 |
| --- | --- |
| 分割终端 | [分割面板](/terminal/windows/split-panes/) |
| 多终端（标签栏） | [标签页](/terminal/windows/tabs/)、[垂直标签页](/terminal/windows/vertical-tabs/) |
| 任务（`tasks.json`） | [YAML 工作流](/terminal/entry/yaml-workflows/)或 [tab configs](/terminal/windows/tab-configs/) |
| 终端配置文件 | [Tab configs](/terminal/windows/tab-configs/) + 每会话 Shell 覆盖 |
| Shell 集成 | 通过 [Warpify](/terminal/warpify/) 内置；支持工作目录追踪和命令级 [Block](/terminal/blocks/) |

Warp 在终端基础之上的扩展功能概览，请参见[在 Warp 中编写代码](/getting-started/quickstart/coding-in-warp/)。
