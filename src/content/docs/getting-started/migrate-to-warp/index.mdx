Warp 的用户来自各种终端、编辑器和 AI 编程工具。本节为每种最常见的迁移来源提供了专属页面，包含分步迁移指南、哪些内容可自动迁移的说明，以及对应你现有功能的 Warp 功能对照表。

选择你要切换的工具：

* [**Claude Code**](/getting-started/migrate-to-warp/migrate-to-warp-from-claude-code/) - 在 Warp 中继续使用 Claude Code，或将 Claude Code 切换为 Warp 的内置 Agent Mode。涵盖上下文、规则和模型设置。
* [**Cursor**](/getting-started/migrate-to-warp/migrate-to-warp-from-cursor/) - 将 Warp 作为 Agent 终端与 Cursor 搭配使用，或用 Warp 的内置代码编辑器和 Agent Mode 完全替代 Cursor。
* [**Ghostty**](/getting-started/migrate-to-warp/migrate-to-warp-from-ghostty/) - 将你的 Ghostty 配置转换为 Warp 设置，并找到快速终端、标签页和 GPU 渲染的等效功能。
* [**iTerm2**](/getting-started/migrate-to-warp/migrate-to-warp-from-iterm2/) - 使用 Warp 内置的 iTerm2 导入工具，只需几次点击即可迁移主题、字体、快捷键绑定和热键窗口。
* [**macOS Terminal**](/getting-started/migrate-to-warp/migrate-to-warp-from-macos-terminal/) - 匹配你的 Terminal.app 设置，发现 Terminal.app 所缺少的分割面板、标签页和 Agent Mode 功能。
* [**VS Code terminal**](/getting-started/migrate-to-warp/migrate-to-warp-from-vs-code-terminal/) - 将 Warp 与 VS Code 搭配使用以获得更丰富的终端体验，或用 Warp 内置的代码编辑器完全替代 VS Code。
* [**Windows Terminal**](/getting-started/migrate-to-warp/migrate-to-warp-from-windows-terminal/) - 将 Windows Terminal 的配置文件、PowerShell 设置和配色方案迁移到 Windows 上的 Warp。

## 从其他工具迁移？

Warp 同样适合从众多其他工具迁移过来的开发者。如果你要从上面未列出的工具切换——例如 Alacritty、WezTerm、Kitty、Hyper，或 GNOME Terminal、Konsole 等 Linux 默认终端——欢迎在我们的 [Discord 社区](https://discord.gg/warpdotdev)留言，帮助我们确定优先支持的范围。
