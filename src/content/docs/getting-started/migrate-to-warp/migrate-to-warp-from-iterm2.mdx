Warp 可自动导入你的 iTerm2 配置文件，只需几次点击即可迁移主题、字体、快捷键绑定、热键窗口等设置。本页介绍导入流程、涵盖范围，以及导入后需要手动重新配置的内容。

## 可自动迁移的内容

Warp 内置了 iTerm2 导入器，可从 `~/Library/Preferences/com.googlecode.iterm2.plist` 读取你的默认配置文件，并导入以下内容：

* **主题** - 前景色、背景色、光标颜色及所有 16 个 ANSI 颜色（如已配置，含浅色和深色变体）。
* **字体** - 字体系列和大小（前提是该字体已安装在你的系统上且 Warp 支持）。
* **默认 Shell** - 如果你在 iTerm2 配置文件中设置了自定义命令。
* **工作目录行为** - Warp 会转换 iTerm2 的"重用上一个会话的目录"等选项。
* **窗口尺寸** - 行数和列数。
* **不透明度和模糊效果。**
* **选中即复制、鼠标和滚动上报，以及 Option 作为 Meta 键的设置。**
* **全局热键** - 如果你使用了热键窗口或热键激活，Warp 会进行映射。

运行导入器的步骤：

1. 在 Warp 中打开 [Command Palette](/terminal/command-palette/)。
2. 搜索 **Import External Settings**。
3. 选择 **iTerm2 Profile: Default**。Warp 仅导入标记为 iTerm2 默认书签的配置文件。
4. 在预览界面选择要保留或跳过的设置。

## 使用 Warp 的 Agent 补充迁移设置

如果导入器未能识别你关心的某项设置——非默认配置文件、非常规快捷键绑定、特定设置——可以让 Warp 的 Agent 直接进行翻译。Warp 提供了一个 [`settings.toml` 文件](/terminal/settings/)和内置的 `modify-settings` 技能，让 Agent 可以读取 iTerm2 的 plist，并将等效值写入 Warp 的设置中。

1. 在 Warp 中，按 `⌘+I` 切换到 [Agent Mode](/agent-platform/local-agents/overview/)。
2. 粘贴如下提示词：

   > 使用 `defaults read com.googlecode.iterm2` 读取我的 iTerm2 偏好设置，并使用 `modify-settings` 技能，将导入器未能涵盖的设置（额外的配置文件、自定义快捷键绑定）迁移到我的 Warp `settings.toml` 中。应用前请显示差异对比。

3. 检查建议的差异并确认。Warp 会热重载 `settings.toml`。

## 需要手动重新配置的内容

以下几项 iTerm2 功能无法直接映射，需要在导入后手动处理：

* **多个配置文件。** Warp 仅导入你的默认配置文件。如果你依赖多个 iTerm2 配置文件，可在 Warp 中创建等效的 [tab configs](/terminal/windows/tab-configs/)。
* **键盘快捷键。** Warp 的[键盘快捷键](/getting-started/keyboard-shortcuts/)开箱即涵盖了大多数 iTerm2 绑定，但自定义绑定需要在 **Settings** > **Keyboard shortcuts** 中重新创建。
* **分割面板和布局。** 使用[分割面板](/terminal/windows/split-panes/)和 [tab configs](/terminal/windows/tab-configs/) 重新构建。
* **触发器（Triggers）。** Warp 没有直接等效功能。可通过 [YAML 工作流](/terminal/entry/yaml-workflows/)或 Agent Mode 实现类似效果。

### 选择你的提示符

导入完成后，选择要使用的[提示符](/terminal/appearance/prompt/)：

1. [**Warp 提示符**](/terminal/appearance/prompt/#warp-prompt) - Warp 的原生提示符，支持拖拽式上下文芯片，包含 Git 分支、目录、时间戳等信息。在 **Settings** > **Appearance** > **Prompt** 中配置。
2. [**Shell 提示符（PS1）**](/terminal/appearance/prompt/#custom-prompt) - 继承你现有的 Shell 提示符配置，保持不变。如果你希望 Warp 与 iTerm2 的提示符完全一致，选择此项。

## Warp 原生等效功能

从 iTerm2 切换后常见的功能查找，及其在 Warp 中的位置：

| iTerm2 中 | Warp 中 |
| --- | --- |
| 热键窗口（Quake 模式） | [全局热键](/terminal/windows/global-hotkey/)（当在 iTerm2 配置文件中检测到时自动导入） |
| 触发器（Triggers） | [YAML 工作流](/terminal/entry/yaml-workflows/)用于可重复操作；Agent Mode 用于基于模式的自动化 |
| 配置文件（Profiles） | [Tab configs](/terminal/windows/tab-configs/) 用于布局；[Warp Drive](/knowledge-and-collaboration/warp-drive/) 用于团队共享配置 |
| 自动补全菜单 | [自动建议](/terminal/command-completions/autosuggestions/) + [Tab 补全](/terminal/command-completions/completions/) |
| 即时回放（Instant Replay） | [会话恢复](/terminal/sessions/session-restoration/) |
| 密码管理器集成 | [Warp Drive 环境变量](/knowledge-and-collaboration/warp-drive/environment-variables/) |

更多迁移后的配置说明，请参见 [Warp 快速入门](/quickstart/)和[自定义 Warp](/getting-started/quickstart/customizing-warp/)。
