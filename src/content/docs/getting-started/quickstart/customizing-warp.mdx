Warp 具有高度的可定制性。无论你主要将 Warp 用作现代终端还是 AI 驱动的开发环境，都可以根据自己的工作方式来个性化体验。终端侧（主题、快捷键绑定、垂直标签页、tab configs）和 AI 侧（模型选择、Agent 自主程度、默认模式）可以独立配置。

使用下面的快速参考表找到你需要的内容，或浏览以下各节获取更多详情。如果你希望在配置之外进行更深度的定制，Warp 的客户端在 [AGPL v3](https://github.com/warpdotdev/warp/blob/master/LICENSE-AGPL) 下开源——详见[为 Warp 做贡献](/support-and-community/community/contributing/)，可构建自定义版本或向上游贡献变更。

## 快速参考

| 要自定义的内容 | 位置 | 快速操作 |
| --- | --- | --- |
| 主题 | **Settings** > **Appearance** | 选择预设或[创建自定义 YAML 主题](/terminal/appearance/custom-themes/) |
| 提示符芯片 | 右键提示符区域 > **Edit prompt** | 拖拽上下文芯片（目录、Git 分支、时间等） |
| AI 模型 | Agent 对话中的模型选择器 | 选择 Claude、GPT、Gemini 或 Auto |
| 快捷键绑定 | **Settings** > **Keyboard shortcuts** | 从其他终端导入或设置自定义快捷键 |
| 垂直标签页 | **Settings** > **Appearance** > **Tabs** | 切换到侧边栏标签页布局，获得更多横向空间 |
| Tab configs | **Settings** > **Features** 或 `/` 菜单 | 保存并恢复带有启动命令的标签页布局 |
| 设置文件 | 设置页脚的 **Open settings file** 按钮 | 直接编辑 [`settings.toml`](/terminal/settings/) 以支持版本控制和脚本操作 |
| 输入格式 | **Settings** > **Appearance** > **Input** | 选择标准模式或经典模式 |
| 应用图标 | **Settings** > **Appearance** > **Icon** | 选择自定义图标（macOS） |
| 字体和文本 | **Settings** > **Appearance** > **Text** | 更改字体、大小和光标样式 |
| Agent 自主程度 | **Settings** > **Agents** > **Profiles** | 设置 Agent 无需询问可执行的操作 |
| 默认模式 | **Settings** > **Agents** > **Warp Agent** > **Input** | 选择新标签页默认以终端模式还是 Agent Mode 打开 |

## 外观

在 Warp 中，前往 **Settings** > **Appearance** 访问以下选项，控制 Warp 的外观：

* **[主题](/terminal/appearance/themes/)** - 从预载主题中选择，或使用 YAML 或背景图片[创建自定义主题](/terminal/appearance/custom-themes/)。
* **[提示符芯片](/terminal/appearance/prompt/)** - 自定义 Warp 提示符中的上下文芯片。右键提示符区域并选择 **Edit prompt**，可拖拽目录、Git 分支、Kubernetes 上下文和时间等芯片。
* **[应用图标](/terminal/appearance/app-icons/)** - 选择自定义应用图标，使 Warp 在 Dock 中与众不同（macOS）。
* **[文本、字体和光标](/terminal/appearance/text-fonts-cursor/)** - 更改字体类型、大小和光标样式。
* **[输入位置](/terminal/appearance/input-position/)** - 将提示符和命令行移到窗口顶部或底部。
* **[大小、不透明度和模糊效果](/terminal/appearance/size-opacity-blurring/)** - 调整窗口透明度和模糊效果。
* **[面板变暗](/terminal/appearance/pane-dimming/)** - 使非活动面板变暗，聚焦于当前面板。

## 布局

使用标签页、面板和窗口配置组织你的工作区。

* **[垂直标签页](/terminal/windows/vertical-tabs/)** - 切换到垂直侧边栏标签页布局，获得更多横向空间，在开启多个会话时也拥有更好的可见性。
* **[标签页](/terminal/windows/tabs/)** - 使用自定义标题和颜色将会话组织到标签页中。右键标签页可选择颜色。
* **[分割面板](/terminal/windows/split-panes/)** - 将任意标签页分割为多个并排或上下排列的面板。
* **[Tab configs](/terminal/windows/tab-configs/)** - 保存并恢复带有预定义面板排列和启动命令的标签页布局。
* **[全局热键](/terminal/windows/global-hotkey/)** - 设置专属热键窗口（Quake 模式），通过键盘快捷键显示和隐藏。

## 输入和编辑器

配置你在终端输入框中的输入和交互方式。

* **[标准模式与经典模式](/terminal/input/classic-input/)** - 标准模式更便于使用 AI 功能，是新用户的默认选项；经典模式类似传统终端提示符。在 **Settings** > **Appearance** > **Input** 中切换。
* **[键盘快捷键](/getting-started/keyboard-shortcuts/)** - Warp 支持常见快捷键，并允许你创建自定义快捷键。从 **Settings** > **Keyboard shortcuts** 管理，或在[迁移](/getting-started/migrate-to-warp/)时从其他终端导入快捷键绑定。
* **[Vim 键盘绑定](/terminal/editor/vim/)** - 在输入编辑器中启用 Vim 键盘绑定以支持键盘驱动的文本编辑。
* **Tab 键行为** - 在 **Settings** > **Features** 中配置 `Tab` 键的行为。可选择接受自动建议或触发补全。

## AI 和模型

控制 Warp Agent 的行为及使用的模型。

* **[模型选择](/agent-platform/capabilities/model-choice/)** - 在任意 Agent 对话的模型选择器中选择你偏好的 AI 模型（Claude、GPT、Gemini 或 Auto）。
* **[Agent 配置文件和权限](/agent-platform/capabilities/agent-profiles-permissions/)** - 配置 Agent 的自主程度：可以自动执行哪些操作、哪些需要审批，以及命令的允许列表/拒绝列表。
* **新会话的默认模式** - 选择新标签页默认以终端模式还是 Agent Mode 打开。在 **Settings** > **Agents** > **Warp Agent** > **Input** 中设置。

## 导入和同步

将现有设置带入 Warp，或跨设备保持设置同步。

* **[从其他终端迁移](/getting-started/migrate-to-warp/)** - 针对从 iTerm2、Ghostty、macOS Terminal、Windows Terminal、VS Code、Cursor、Claude Code 等工具切换到 Warp 的专属指南，包括 iTerm2 的自动设置导入。
* **[设置同步](/terminal/more-features/settings-sync/)** - 跨设备同步你的 Warp 设置（Beta）。
