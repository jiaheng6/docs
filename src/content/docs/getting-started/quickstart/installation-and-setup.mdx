## 安装 Warp

:::caution
**访问[已知问题](/support-and-community/troubleshooting-and-support/known-issues/)，获取更多关于 Warp 设置和故障排除的详情。**
:::

<Tabs>
  <TabItem label="macOS">
    :::note
    **最低要求：** Intel 或 Apple silicon，macOS 10.14 或更高版本，以及支持 [Metal](https://support.apple.com/en-us/HT205073) 的硬件。
    :::

    **下载 Warp 并拖入你的 Applications 文件夹**

    <VideoEmbed url="https://www.warp.dev/download" title="Download Warp" />

    **使用 Homebrew 安装，运行以下命令**

    ```bash
    brew install --cask warp
    ```

    安装完成后，你可以在 Applications 文件夹中找到 Warp。
  </TabItem>
  <TabItem label="Windows">
    :::note
    **最低要求：** Warp 需要 Windows 10 1809 版本（Build 17763）或更高版本，Windows Server 2019（Build 17763）和 Windows Server 2022（Build 20348）或更高版本。这是 [Windows Pseudo Console (ConPTY)](https://devblogs.microsoft.com/commandline/windows-command-line-introducing-the-windows-pseudo-console-conpty/) 的要求。
    :::

    **下载 Warp，然后打开并运行安装程序**

    <VideoEmbed url="https://www.warp.dev/download" title="Download Warp" />

    **使用 WinGet 安装，运行以下命令**

    ```powershell
    winget install Warp.Warp
    ```

    安装完成后，你可以在开始菜单中找到 Warp。
  </TabItem>
  <TabItem label="Linux">
    :::note
    **最低要求：** glibc >= 2.31（2020 年 2 月发布）的 Linux 发行版，以及支持 _[OpenGL ES 3.0+ 或 Vulkan](https://github.com/gfx-rs/wgpu?tab=readme-ov-file#supported-platforms)_ 的系统。

    包括（但不限于）以下发行版：

    * Ubuntu 20.04
    * Debian 11（"bullseye"）
    * Fedora 32
    * Arch Linux
    :::

    **访问 Warp 下载页面，查看完整的 Linux 安装选项列表**

    <VideoEmbed url="https://www.warp.dev/download" title="Download Warp" />

    **基于 Debian 和 Ubuntu 的发行版**

    最简单的安装方式是下载 [x64 .deb 包](https://app.warp.dev/download?package=deb)或 [ARM64 deb 包](https://app.warp.dev/download?package=deb_arm64)。下载后，使用以下命令安装：

    ```
    sudo apt install ./<file>.deb
    ```

    安装 .deb 包会自动配置 Warp apt 仓库和签名密钥，用于自动更新 Warp 并验证下载包的完整性。

    或者，你也可以手动配置 Warp apt 仓库并运行以下命令安装 Warp：

    ```
    sudo apt-get install wget gpg
    wget -qO- https://releases.warp.dev/linux/keys/warp.asc | gpg --dearmor > warpdotdev.gpg
    sudo install -D -o root -g root -m 644 warpdotdev.gpg /etc/apt/keyrings/warpdotdev.gpg
    sudo sh -c 'echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/warpdotdev.gpg] https://releases.warp.dev/linux/deb stable main" > /etc/apt/sources.list.d/warpdotdev.list'
    rm warpdotdev.gpg
    sudo apt update && sudo apt install warp-terminal
    ```

    **基于 RHEL、Fedora 和 CentOS 的发行版**

    最简单的安装方式是下载 [x64 .rpm 包](https://app.warp.dev/download?package=rpm)或 [ARM64 .rpm 包](https://app.warp.dev/download?package=rpm_arm64)。下载后，使用以下命令安装：

    ```bash
    sudo dnf install ./<file>.rpm
    ```

    安装 .rpm 包会自动配置 Warp yum 仓库。首次更新时，`dnf` 会获取用于验证下载包完整性的签名密钥。

    或者，你也可以手动配置 Warp yum 仓库并运行以下命令安装 Warp：

    ```bash
    sudo rpm --import https://releases.warp.dev/linux/keys/warp.asc
    sudo sh -c 'echo -e "[warpdotdev]\nname=warpdotdev\nbaseurl=https://releases.warp.dev/linux/rpm/stable\nenabled=1\ngpgcheck=1\ngpgkey=https://releases.warp.dev/linux/keys/warp.asc" > /etc/yum.repos.d/warpdotdev.repo'
    sudo dnf install warp-terminal
    ```

    **基于 Arch Linux 的发行版**

    最简单的安装方式是下载 [x64 .pkg.tar.zst 包](https://app.warp.dev/download?package=pacman)或 [ARM64 pacman 包](https://app.warp.dev/download?package=pacman_arm64)。下载后，使用以下命令安装：

    ```bash
    sudo pacman -U ./<file>.pkg.tar.zst
    ```

    首次通过应用更新 Warp 时，它会引导你完成 Warp pacman 仓库和签名密钥的配置。

    或者，你也可以手动配置 Warp pacman 仓库并运行以下命令安装 Warp：

    ```bash
    sudo sh -c "echo -e '\n[warpdotdev]\nServer = https://releases.warp.dev/linux/pacman/\$repo/\$arch' >> /etc/pacman.conf"
    sudo pacman-key -r "linux-maintainers@warp.dev"
    sudo pacman-key --lsign-key "linux-maintainers@warp.dev"
    sudo pacman -Sy warp-terminal
    ```

    **基于 OpenSUSE 和 SLE 的发行版**

    Warp yum 仓库同样适用于基于 OpenSUSE 和 SLE 的系统。下载 [x64 .rpm 包](https://app.warp.dev/download?package=rpm)或 [ARM64 .rpm 包](https://app.warp.dev/download?package=rpm_arm64)。下载后，使用以下命令安装：

    ```bash
    sudo zypper install ./<file>.rpm
    ```

    安装 .rpm 包会自动配置 Warp yum 仓库。首次更新时，`zypper` 会获取用于验证下载包完整性的签名密钥。

    或者，你也可以手动配置 Warp yum 仓库并运行以下命令安装 Warp：

    ```bash
    sudo rpm --import https://releases.warp.dev/linux/keys/warp.asc
    sudo sh -c 'echo -e "[warpdotdev]\nname=warpdotdev\ntype=rpm-md\nbaseurl=https://releases.warp.dev/linux/rpm/stable\nenabled=1\nautorefresh=1\ngpgcheck=1\ngpgkey=https://releases.warp.dev/linux/keys/warp.asc\nkeeppackages=0" > /etc/zypp/repos.d/warpdotdev.repo'
    sudo zypper install warp-terminal
    ```

    **AppImage**

    我们还提供 [AppImage](https://appimage.org)，即 Warp 的单文件可执行版本。推荐通过包管理器安装 Warp，以确保系统安装了所有必要的依赖项。

    可使用以下命令下载 Warp AppImage：

    ```bash
    # 在 x64 系统上
    curl -L "https://app.warp.dev/download?package=appimage" -o Warp-x64.AppImage
    chmod +x Warp-x64.AppImage
    ```

    ```bash
    # 在 ARM64 系统上
    curl -L "https://app.warp.dev/download?package=appimage_arm64" -o Warp-ARM64.AppImage
    chmod +x Warp-ARM64.AppImage
    ```

    **在 Linux 上运行 Warp**

    如果你通过包管理器安装，可以在桌面管理器中找到 Warp，或在终端运行 `warp-terminal`。如果你使用 AppImage，可以进入 AppImage 所在目录并运行 `./Warp-*.AppImage` 来启动。

## 从源码构建

Warp 的客户端在 [AGPL v3](https://github.com/warpdotdev/warp/blob/master/LICENSE-AGPL) 下开源，因此你可以从 [`warpdotdev/warp`](https://github.com/warpdotdev/warp) 自行构建。

克隆仓库，初始化工具链依赖，并启动开发构建：

```bash
git clone https://github.com/warpdotdev/warp.git
cd warp
./script/bootstrap
cargo run
```

`cargo run` 会启动从本地代码构建的 `warp-oss` 二进制文件。完整的先决条件（macOS 上的 Xcode、固定的 Rust 工具链、`protoc`）和开发环境设置，请参见仓库的 `README.md` 和 `CONTRIBUTING.md`。

:::note
日常使用请使用官方构建版本。自行构建的 `warp-oss` 二进制文件使用独立的配置和数据目录，可以与官方 Warp 并行运行而不会冲突，但不会自动更新，也不具备生产环境的代码签名身份。仅用于开发、审计或向上游贡献代码时使用。
:::

## 初始设置

### 登录 Warp（可选）

安装完成后，你可以选择通过右上角的"Sign up"按钮创建 Warp 账号，或前往 **Settings** > **Account** > **Sign up**。此步骤可以跳过。如果你在登录时遇到问题，请参见[登录故障排除](/support-and-community/troubleshooting-and-support/troubleshooting-login-issues/)页面。

:::note
如果你使用 Google 或 GitHub 注册，Warp 仅获取关联的电子邮件地址。访问[隐私政策](/support-and-community/privacy-and-security/privacy/)页面，了解更多关于 Warp 隐私处理方式的详情。
:::

### 离线使用 Warp

只有第一次打开 Warp 应用时才需要网络连接。一旦打开，[Warp 可在无网络连接的情况下运行](/support-and-community/troubleshooting-and-support/using-warp-offline/)，但 AI 和实时协作等需要网络连接的功能将不可用。

### 导入你的设置

如果你正在从其他终端、编辑器或 AI 编程工具迁移到 Warp，请参见[迁移到 Warp](/getting-started/migrate-to-warp/) 文档，其中提供了各迁移来源的专属指南，包括设置导入步骤和功能对照。

### 设置 Warp 的默认 Shell

Warp 默认会尝试加载你的登录 Shell。目前，Warp 支持 bash、fish、zsh 和 PowerShell（pwsh）。如果你的登录 Shell 是其他类型（例如 Nushell），Warp 将默认加载 zsh。

Zsh 是 macOS 的默认登录和交互式 Shell（自 2019 年 macOS Catalina 起取代 bash）。大多数 Linux 发行版的默认 Shell 是 bash。

你可以前往 **Settings** > **Features** > **Session** 更改默认 Shell。在"新会话的启动 Shell"部分，选择你希望 Warp 使用的 Shell。
