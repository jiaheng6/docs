## 如何访问

* 在 [Command Palette](/terminal/command-palette/) 中输入 "Autosuggestions" 来切换开关。

:::note
**终端技巧**

你可以将接受自动建议的快捷键更改为 `Tab`。在 **Settings** > **Features** > **Terminal Input** 中的 "Tab key behavior" 设置中进行配置。_注意：这将把打开补全菜单的快捷键更新为 `CTRL-SPACE`。你也可以在 **Settings** > **Features** > **Terminal Input** 中启用 "Open completions menu as you type"，让补全菜单自动打开。_
:::

## 如何使用

<Tabs>
  <TabItem label="macOS">
    有几种方式可以完整或部分接受自动建议：

    * 使用 `RIGHT` 方向键或 `CTRL-F` 完整接受自动建议。
    * 当光标位于缓冲区末尾时，`CTRL-E` 也可以完成自动建议。
    * `CTRL-RIGHT` 可用于逐个组件地部分完成自动建议。
  </TabItem>
  <TabItem label="Windows">
    有几种方式可以完整或部分接受自动建议：

    * 使用 `RIGHT` 方向键或 `CTRL-F` 完整接受自动建议。
    * `END` 跳到输入编辑器的最后一个字符，然后 `RIGHT` 完成自动建议。
    * `CTRL-SHIFT-RIGHT` 可用于逐个组件地部分完成自动建议。
  </TabItem>
  <TabItem label="Linux">
    有几种方式可以完整或部分接受自动建议：

    * 使用 `RIGHT` 方向键或 `CTRL-F` 完整接受自动建议。
    * `CTRL-E` 跳到输入编辑器的最后一个字符，然后 `RIGHT` 完成自动建议。
    * `CTRL-SHIFT-RIGHT` 可用于逐个组件地部分完成自动建议。
  </TabItem>
</Tabs>
