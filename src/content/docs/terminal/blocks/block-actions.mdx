## 访问 Block 操作

有两种方式可以访问 Block 操作：

1. 将鼠标悬停在 Block 上，点击右侧的菜单（三个点）按钮。
2. 右键点击 Block。

<VideoEmbed url="https://www.loom.com/share/3dec25e548d4484aa3dd6437869e2bbf?hide_owner=true&hide_share=true&hide_title=true&hideEmbedTopBar=true" title="Accessing Block Actions" />

## 复制 Block 的输入/输出

对于命令 Block，你可以`右键点击` Block 或点击上下文菜单，复制 Block 的命令、输出或两者。

对于 AI Block，你可以`右键点击`以复制提示词、输出、两者或整个对话。

<VideoEmbed url="https://www.loom.com/share/9ad67eca0a8d47afb82cc1acba617f3c?hide_owner=true&hide_share=true&hide_title=true&hideEmbedTopBar=true" title="Copy Block Actions" />

## 分享 Block

通过创建网页永久链接，轻松与同事或队友分享 Block。这会保留格式，使调试和分享输出变得简单。[查看 Block 分享页面。](/terminal/blocks/block-sharing/)

## 为 Block 添加书签

无论 Block 在终端历史中的位置如何，都能快速导航到重要的 Block。

<Tabs>
  <TabItem label="macOS">
    为 Block 添加书签的方式：

    1. 在 Block 上下文菜单中选择 **Toggle bookmark**
    2. 使用 `CMD-B` 快捷键为选中的 Block 添加书签

    导航到已书签标记的 Block：

    * 点击指示符。\
      指示符的位置反映了该 Block 在 Block 历史记录中的大致位置。将鼠标悬停在指示符上会显示该 Block 的快照，包括其提示符、命令和输出的最后两行。
    * 按 `OPTION-UP` 和 `OPTION-DOWN`
  </TabItem>
  <TabItem label="Windows">
    为 Block 添加书签的方式：

    1. 在 Block 上下文菜单中选择 **Toggle bookmark**
    2. 使用 `CTRL-SHIFT-B` 快捷键为选中的 Block 添加书签

    导航到已书签标记的 Block：

    * 点击指示符。\
      指示符的位置反映了该 Block 在 Block 历史记录中的大致位置。将鼠标悬停在指示符上会显示该 Block 的快照，包括其提示符、命令和输出的最后两行。
    * 按 `ALT-UP` 和 `ALT-DOWN`
  </TabItem>
  <TabItem label="Linux">
    为 Block 添加书签的方式：

    1. 点击 Block 右上角的书签图标
    2. 在 Block 上下文菜单中选择 **Toggle bookmark**
    3. 使用 `CTRL-SHIFT-B` 快捷键为选中的 Block 添加书签

    导航到已书签标记的 Block：

    * 点击指示符。\
      指示符的位置反映了该 Block 在 Block 历史记录中的大致位置。将鼠标悬停在指示符上会显示该 Block 的快照，包括其提示符、命令和输出的最后两行。
    * 按 `ALT-UP` 和 `ALT-DOWN`
  </TabItem>
</Tabs>

:::note
书签仅在会话打开期间持续存在，关闭会话后书签将丢失。如果你想保存命令和输出以供日后使用，请[分享该 Block](/terminal/blocks/block-sharing/)。
:::

## 在 Block 内搜索

快速在 Block 中查找重要信息。[查看查找页面](/terminal/blocks/find/)

<Tabs>
  <TabItem label="macOS">
    选中一个 Block，按"Find Within Block"或使用 `CMD-F` 在 Block 内搜索。
  </TabItem>
  <TabItem label="Windows">
    选中一个 Block，按"Find Within Block"或使用 `CTRL-SHIFT-F` 在 Block 内搜索。
  </TabItem>
  <TabItem label="Linux">
    选中一个 Block，按"Find Within Block"或使用 `CTRL-SHIFT-F` 在 Block 内搜索。
  </TabItem>
</Tabs>

## 过滤 Block

在 Warp 中原生过滤 Block 的输出行，快速聚焦于 Block 的某个子集。[查看 Block 过滤页面](/terminal/blocks/block-filtering/)

<Tabs>
  <TabItem label="macOS">
    * 默认使用快捷键 `OPT-SHIFT-F` 切换选中或最新 Block 的过滤
    * 在 Block 上下文菜单中选择 `Toggle Block Filter`
  </TabItem>
  <TabItem label="Windows">
    * 使用快捷键 `ALT-SHIFT-F` 切换选中或最新 Block 的过滤
    * 在 Block 上下文菜单中选择 `Toggle Block Filter`
  </TabItem>
  <TabItem label="Linux">
    * 使用快捷键 `ALT-SHIFT-F` 切换选中或最新 Block 的过滤
    * 在 Block 上下文菜单中选择 `Toggle Block Filter`
  </TabItem>
</Tabs>
