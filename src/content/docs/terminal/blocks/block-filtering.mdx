在 Warp 中过滤 Block 的输出行，快速聚焦于 Block 的某个子集。你可以按纯文本、正则表达式、反向过滤或区分大小写进行过滤，还可以添加上下文行以查看匹配项周围的输出。过滤不会删除任何输出行，因此你可以清除过滤以返回原始输出。

## 如何过滤 Block

为 Block 应用过滤：

1. 点击 Block 右上角的过滤图标。将出现一个过滤编辑器，左侧有一个大输入框和两个按钮，右侧有一个小输入框。
2. 在左侧输入框中输入内容以过滤 Block。只会显示包含匹配过滤查询的文本的行。
3. （可选）点击正则表达式、区分大小写搜索或反向过滤按钮以启用。
4. （可选）在右侧输入框中输入数字，以在匹配行周围添加上下文行。

<Tabs>
  <TabItem label="macOS">
    你也可以通过以下方式切换过滤：

    * 默认使用快捷键 `OPT-SHIFT-F` 切换选中或最新 Block 的过滤
    * 在 Block 上下文菜单中选择 `Toggle Block Filter`
  </TabItem>
  <TabItem label="Windows">
    你也可以通过以下方式开关过滤：

    * 使用快捷键 `ALT-SHIFT-F` 切换选中或最新 Block 的过滤
    * 在 Block 上下文菜单中选择 `Toggle Block Filter`
  </TabItem>
  <TabItem label="Linux">
    你也可以通过以下方式开关过滤：

    * 使用快捷键 `ALT-SHIFT-F` 切换选中或最新 Block 的过滤
    * 在 Block 上下文菜单中选择 `Toggle Block Filter`
  </TabItem>
</Tabs>

:::note
在未应用过滤的 Block 上切换过滤将打开过滤编辑器。如果关闭过滤，再次开启时将应用相同的过滤条件。
:::
