## 这是什么

命令可以启动后台进程，这些进程在命令退出后仍会继续运行。你也可以直接从 shell 启动后台进程，例如使用 `&` 运行。

如果 Warp 收到可能来自后台进程的输出，该输出会进入一个_后台 Block_。后台 Blocks 的行为与普通 Blocks 类似，但没有关联的命令。

这样你就可以对后台输出使用 Warp 的所有 Block 功能，例如分享和书签标记。

## 如何使用

后台 Blocks 会根据需要自动创建，穿插在运行的普通 Blocks 之间。如果你在后台进程仍在产生输出时运行命令，该输出会被拆分成多个 Block，与你的命令交错出现。

## 后台 Blocks 故障排除

由于 Warp 不知道_哪个_进程产生了特定的输出，因此存在一些限制：

* 如果后台进程在前台命令运行于普通 Block 中时写入输出，该输出会进入那个 Block。
* 如果同时有多个后台进程在运行，它们的输出可能会混在一起。

此外，如果你在另一个命令运行时开始输入命令（预输入），在某些情况下 Warp 会将未完成的命令误认为后台输出。最常见的原因是在使用低于 4.0 版本的 bash（例如，删除并重新输入部分内容）时编辑预输入内容。
