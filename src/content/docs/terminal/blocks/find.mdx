## 这是什么

查找功能在所有 Blocks 中从底部向上搜索匹配项，甚至可以限定在特定 Block 中搜索。

:::note
由于命令输出包含在 Blocks 中，你仍可以在调用查找时使用输入编辑器。
:::

## 如何访问

<Tabs>
  <TabItem label="macOS">
    1. 按 `CMD-F` 打开查找视图，在终端中进行搜索（限定在当前面板内）。
    2. 在查找模态框中，你还可以启用正则表达式切换、在选中的 Block 中查找，或切换区分大小写搜索。
  </TabItem>
  <TabItem label="Windows">
    1. 按 `CTRL-SHIFT-F` 打开查找视图，在终端中进行搜索（限定在当前面板内）。
    2. 在查找模态框中，你还可以启用正则表达式切换、在选中的 Block 中查找，或切换区分大小写搜索。
  </TabItem>
  <TabItem label="Linux">
    1. 按 `CTRL-SHIFT-F` 打开查找视图，在终端中进行搜索（限定在当前面板内）。
    2. 在查找模态框中，你还可以启用正则表达式切换、在选中的 Block 中查找，或切换区分大小写搜索。
  </TabItem>
</Tabs>
