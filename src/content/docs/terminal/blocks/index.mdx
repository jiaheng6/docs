## Blocks 是什么？

Blocks 让我们能够轻松地：

* 复制命令
* 复制命令的输出
* 直接滚动到命令输出的开头
* 重新输入命令
* 分享命令及其输出（带格式！）
* 为命令添加书签

:::note

:::
