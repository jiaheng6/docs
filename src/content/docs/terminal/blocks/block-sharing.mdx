通过永久链接或 HTML 嵌入方式分享你的 Blocks。你可以通过打开上下文菜单并复制命令、输出或提示符来开始使用共享 Blocks。

## 如何分享 Blocks

<Tabs>
  <TabItem label="macOS">
    按照以下步骤分享你的 Blocks：

    1. 在已完成的 Block 上，点击上下文菜单并选择 **Share...**，或选中该 Block 后按 `CMD-SHIFT-S`。
    2. 弹出一个模态框，让你为 Block 命名，并通过选择要分享的 Block 部分（如命令、输出、提示符等）进行自定义。
    3. 根据分享方式点击"Create link"或"Get embed"。
    4. 链接或嵌入代码片段将被复制到剪贴板。
  </TabItem>
  <TabItem label="Windows">
    按照以下步骤分享你的 Blocks：

    1. 在已完成的 Block 上，点击上下文菜单并选择 **Share...**，或在 **Settings** > **Keyboard shortcuts** 中设置 Share Block 的键绑定。
    2. 弹出一个模态框，让你为 Block 命名，并通过选择要分享的 Block 部分（如命令、输出、提示符等）进行自定义。
    3. 根据分享方式点击"Create link"或"Get embed"。
    4. 链接或嵌入代码片段将被复制到剪贴板。
  </TabItem>
  <TabItem label="Linux">
    按照以下步骤分享你的 Blocks：

    1. 在已完成的 Block 上，点击上下文菜单并选择 **Share...**，或在 **Settings** > **Keyboard shortcuts** 中设置 Share Block 的键绑定。
    2. 弹出一个模态框，让你为 Block 命名，并通过选择要分享的 Block 部分（如命令、输出、提示符等）进行自定义。
    3. 根据分享方式点击"Create link"或"Get embed"。
    4. 链接或嵌入代码片段将被复制到剪贴板。
  </TabItem>
</Tabs>

:::note
如果你在分享 Block 时遇到问题，请查看我们已知问题中的[故障排除步骤](/support-and-community/troubleshooting-and-support/known-issues/#online-features-dont-work)。
:::

## 嵌入 Blocks

创建并将 Block 嵌入到网页中，帮助读者跟随技术文档操作。读者可以像在 Warp 中操作 Block 一样与嵌入的 Block 交互，支持上下文菜单和样式。点击"Get embed"后，Warp 会将 `iframe` 复制到剪贴板。以下是一个示例 `iframe`：

```html
<iframe src="https://app.warp.dev/block/embed/qn0g1CqQnkYjEafPH5HCVT"
title="server script error" style="width: 712px; height: 397px; border:0;
overflow:hidden;" allow="clipboard-read; clipboard-write"></iframe>
```

## 管理已分享的 Blocks

你可以通过前往 **Settings** > **Shared blocks** 来取消分享 Block。目前，已分享的 Block 任何持有链接的人都可以访问。

## 链接预览

共享的永久链接还会显示你代码的预览，让每个链接都能快速了解上下文。

:::note
兼容任何支持 Open Graph 或 Twitter meta 标签的平台。例如 Slack、Twitter、Facebook、Telegram、Notion 等……
:::
