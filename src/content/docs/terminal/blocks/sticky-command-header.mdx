:::note
对于占满全屏的长时间运行命令，固定标题仅在你开始向上滚动后才会显示。这是为了防止标题遮挡像 `git log` 这类模拟全屏应用的命令顶部输出内容。
:::

## 如何访问固定命令标题

<Tabs>
  <TabItem label="macOS">
    * 固定命令标题默认启用。
    * 通过前往 **Settings** > **Features** > **General** > 切换"Show sticky command header"来开关固定命令标题。
    * 在 [Command Palette](/terminal/command-palette/) 中搜索"Sticky Command Header"或按 `CTRL-CMD-S` 来切换。
    * 还可以使用 `CTRL-S` 来"Toggle Sticky Command Header in Active Pane"。这不会完全禁用该功能，只会在当前会话中最小化它。
  </TabItem>
  <TabItem label="Windows">
    * 固定命令标题默认启用。
    * 通过前往 **Settings** > **Features** > **General** > 切换"Show sticky command header"来开关固定命令标题。
    * 在 [Command Palette](/terminal/command-palette/) 中搜索"Sticky Command Header"或在 **Settings** > **Keyboard shortcuts** 中设置键绑定来切换。
    * 还可以在 Command Palette 中或在 **Settings** > **Keyboard shortcuts** 中设置键绑定来"Toggle Sticky Command Header in Active Pane"。这不会完全禁用该功能，只会在当前会话中最小化它。
  </TabItem>
  <TabItem label="Linux">
    * 固定命令标题默认启用。
    * 通过前往 **Settings** > **Features** > **General** > 切换"Show sticky command header"来开关固定命令标题。
    * 在 [Command Palette](/terminal/command-palette/) 中搜索"Sticky Command Header"或在 **Settings** > **Keyboard shortcuts** 中设置键绑定来切换。
    * 还可以在 Command Palette 中或在 **Settings** > **Keyboard shortcuts** 中设置键绑定来"Toggle Sticky Command Header in Active Pane"。这不会完全禁用该功能，只会在当前会话中最小化它。
  </TabItem>
</Tabs>

## 如何使用固定命令标题

* 如果一个 Block 有大量输出（例如 `seq 1 1000`），该 Block 的标题将显示在当前窗口、标签页或面板的顶部。
* 点击固定命令标题可快速跳转到 Block 的顶部。
* 激活时，你也可以通过点击标题中间的上/下箭头来最小化当前面板的固定命令标题。
