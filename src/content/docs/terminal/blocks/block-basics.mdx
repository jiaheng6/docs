## 基础知识

* Blocks 将你的命令和命令输出分组在一起
* 输入编辑器可以固定在底部、固定在顶部，或从顶部开始。
* Blocks 从底部向上增长。
* Blocks 有颜色标记。以非零退出码退出的 Blocks 有红色背景和红色侧边栏。

:::note
自己试试吧！\
输入 `xyz`（或其他不存在的命令）并按 `ENTER`
:::

## 创建 Block

1. 在屏幕底部的输入编辑器中执行命令（输入 `ls` 并按 `ENTER`）。
2. 你的命令和输出会被组合到一个 Block 中。
3. 尝试执行另一个命令（输入 `echo hello` 并按 `ENTER`）。
4. Warp 将你新创建的 Block 添加到底部（直接在输入编辑器上方）。

## 选择单个 Block

<Tabs>
  <TabItem label="macOS">
    * 使用鼠标：点击一个 Block。
    * 或使用键盘：按 `CMD-UP`（如果输入固定在顶部则按 `CMD-DOWN`）选择最近执行的 Block，然后使用 `UP ↑` 和 `DOWN ↓` 方向键导航到目标 Block。
    * 对于较长的 Blocks：
      * 可以点击"Jump to the bottom of this block"。
      * 可以按 `SHIFT-CMD-UP`/`SHIFT-CMD-DOWN` 滚动到选中 Block 的顶部/底部。
      * 从 [Command Palette](/terminal/command-palette/) 也可以"Scroll to the top/bottom of selected block"。
  </TabItem>
  <TabItem label="Windows">
    * 使用鼠标：点击一个 Block。
    * 或使用键盘：按 `CTRL-UP`（如果输入固定在顶部则按 `CTRL-DOWN`）选择最近执行的 Block，然后使用 `UP ↑` 和 `DOWN ↓` 方向键导航到目标 Block。
    * 对于较长的 Blocks：
      * 可以点击"Jump to the bottom of this block"。
      * 可以按 `CTRL-SHIFT-UP`/`CTRL-SHIFT-DOWN` 滚动到选中 Block 的顶部/底部。
      * 从 [Command Palette](/terminal/command-palette/) 也可以"Scroll to the top/bottom of selected block"。
  </TabItem>
  <TabItem label="Linux">
    * 使用鼠标：点击一个 Block。
    * 或使用键盘：按 `CTRL-UP`（如果输入固定在顶部则按 `CTRL-DOWN`）选择最近执行的 Block，然后使用 `UP ↑` 和 `DOWN ↓` 方向键导航到目标 Block。
    * 对于较长的 Blocks：
      * 可以点击"Jump to the bottom of this block"。
      * 可以按 `CTRL-SHIFT-UP`/`CTRL-SHIFT-DOWN` 滚动到选中 Block 的顶部/底部。
      * 从 [Command Palette](/terminal/command-palette/) 也可以"Scroll to the top/bottom of selected block"。
  </TabItem>
</Tabs>

## 选择多个 Block

<Tabs>
  <TabItem label="macOS">
    * 按住 `CMD` 点击另一个 Block 以切换该 Block 的选中状态，或
    * 按住 `SHIFT` 点击另一个 Block 以选择一个 Block 范围，或
    * 使用 `SHIFT-UP ↑` 或 `SHIFT-DOWN ↓` 向上或向下扩展当前选区（带较粗边框的 Block）。
  </TabItem>
  <TabItem label="Windows">
    * 按住 `CTRL-SHIFT` 点击另一个 Block 以切换该 Block 的选中状态，或
    * 按住 `SHIFT` 点击另一个 Block 以选择一个 Block 范围，或
    * 使用 `SHIFT-UP ↑` 或 `SHIFT-DOWN ↓` 向上或向下扩展当前选区（带较粗边框的 Block）。
  </TabItem>
  <TabItem label="Linux">
    * 按住 `CTRL-SHIFT` 点击另一个 Block 以切换该 Block 的选中状态，或
    * 按住 `SHIFT` 点击另一个 Block 以选择一个 Block 范围，或
    * 使用 `SHIFT-UP ↑` 或 `SHIFT-DOWN ↓` 向上或向下扩展当前选区（带较粗边框的 Block）。
  </TabItem>
</Tabs>

## 在 Blocks 之间导航

<Tabs>
  <TabItem label="macOS">
    * **鼠标或滚动条** - 使用鼠标、触控板或滚动条进行滚动。
    * **方向键** - 选中一个 Block 后使用 `UP ↑` 和 `DOWN ↓` 在 Blocks 之间移动。
    * **翻页滚动** - 按 `PAGE UP` 或 `PAGE DOWN` 按页滚动。
    * **跳转到顶部或底部** - 按 `HOME` 或 `END` 滚动到终端输出的顶部或底部。
    * **在选中的 Block 内滚动** - 按 `SHIFT-CMD-UP` 或 `SHIFT-CMD-DOWN` 滚动到选中 Block 的顶部或底部。
    * **每次滚动一行** - 可以在 Settings > Keyboard shortcuts 中配置"Scroll Terminal output up/down one line"的键盘快捷键，或从 [Command Palette](/terminal/command-palette/) 访问。
    * 当命令的输出被截断时，Warp 会将[固定命令标题](/terminal/blocks/sticky-command-header/)固定在顶部，显示该 Block 对应的命令。点击标题将滚动屏幕到 Block 的开头。
  </TabItem>
  <TabItem label="Windows">
