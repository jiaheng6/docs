我们认识到需要改善视障用户的体验——据我们所知，其他终端模拟器应用在这一领域做得并不好。本文档总结了我们迄今为止的工作、Warp 与 VoiceOver 的配合方式，并概述了与典型工作流的主要差异。有关功能文档及其键盘快捷键，请前往文档中对应功能的专属页面。

**请注意，这项工作仍在进行中，当前状态并非 Warp 无障碍访问的最终形态**。

## 如何配合 VoiceOver 使用 Warp？

使用 Homebrew 安装 Warp 是开始配合 VoiceOver 使用的最佳方式：

`brew install warp`

这将确保你可以自动接收所有未来更新，无需经历 macOS 标准的拖放安装流程。

安装完成后，Warp 应与 VoiceOver 无缝协作，开始通告屏幕上发生的事情以及你可以执行的操作。这可能与其他应用有很大不同——Warp 会主动通告内容，让你了解正在发生的事情。目前暂不支持使用 VO 快捷键在不同 UI 元素之间导航。

安装后，系统会要求你登录。Warp 还会发送遥测数据，我们用于改善整体用户体验。你可以在[隐私部分](/support-and-community/privacy-and-security/privacy/)了解更多相关信息。

登录流程需要你在应用和浏览器之间切换。在开始享受我们的新终端应用之前，最后一步是填写引导调查问卷。

主终端窗口与其他终端没有太大区别——有一个输入命令的地方（Command Input）和一个之前执行的命令及其输出列表。Warp 将这些内容分组——每个命令和输出构成一个 Block。你可以使用键盘导航 Block，以便轻松查看命令内容、了解是否成功执行以及查看输出，同时也更方便地复制命令、输出或两者以供进一步处理。

发现新功能和操作的主要入口是我们的 Command Palette，你可以通过 cmd-p 快捷键访问。

## 与常规 VoiceOver 工作流的区别

你可能会注意到，典型的 VoiceOver 导航键或设置目前在 Warp 中无法使用。简而言之，这与我们的 UI 框架目前的实现方式有关，我们目前尚未提供使用键盘导航 UI 元素的方式。

相反，每当你执行某个操作和/或后台发生某些事情时，Warp 都会向你通告，让你了解正在发生的事情以及你可以采取的可能操作。由于这是一个终端，我们从一开始就关注所有用户操作的键盘可访问性，因此几乎所有功能都已分配了键盘绑定。你可以按照此 GitHub 仓库的指南调整默认键盘绑定：[https://github.com/warpdotdev/keysets](https://github.com/warpdotdev/keysets)。你也可以随时使用 cmd-p 检查键盘绑定或执行特定操作。

### 无障碍相关操作

一些无障碍特定设置可通过 Command Palette 访问。例如，你可以调整消息的详细程度级别。只需进入 [Command Palette](/terminal/command-palette/) 并输入 "a11y" 即可发现相关选项及其键盘绑定。

### 语音输入

Warp 支持语音输入作为与终端交互的替代方式。这对于偏好或需要使用语音命令而非打字的用户特别有帮助。你可以使用语音输入来：

* 执行终端命令
* 询问关于命令用法的问题
* 执行复杂的多步骤操作

语音输入可在 **Settings** > **Agents** > **Warp Agent** > **Voice** 中启用。有关语音功能和设置的详细信息，请参阅我们的[语音文档](/agent-platform/local-agents/interacting-with-agents/voice/)。

## 未来工作

虽然 Warp 的功能并非全部都已具备无障碍支持，但我们已建立了围绕向主应用发布新功能和更改的流程，以确保所有新代码都提供适当的无障碍通告。

这不是理想的最终实现。我们很乐意听取你关于如何改进的想法和意见。这项工作最重要的里程碑是添加对使用键盘导航 UI 元素的支持。欢迎试用 Warp，并请毫不犹豫地[分享你的反馈](/support-and-community/troubleshooting-and-support/sending-us-feedback/)。
