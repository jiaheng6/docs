## 如何访问

<Tabs>
  <TabItem label="macOS">
    将鼠标悬停在你想检查的命令部分，或按 `CMD-SHIFT-I` 检查光标当前位置。
  </TabItem>
  <TabItem label="Windows">
    将鼠标悬停在你想检查的命令部分，或按 `CTRL-SHIFT-I` 检查光标当前位置。
  </TabItem>
  <TabItem label="Linux">
    将鼠标悬停在你想检查的命令部分，或按 `CTRL-SHIFT-I` 检查光标当前位置。
  </TabItem>
</Tabs>
