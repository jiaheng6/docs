## 什么是语法高亮

Warp 的[输入编辑器](/terminal/editor/)支持语法高亮功能。它会对命令的各个部分进行着色，帮助区分子命令、选项/标志、参数和变量。

:::caution
新安装的应用或新创建的别名在你打开新的 Warp 会话（新窗口、标签页或分屏）之前不会触发语法高亮，即使你在当前会话中 `source` 了 RC 文件也不例外。
:::

### 如何访问语法高亮

启用语法高亮后，Warp 的[输入编辑器](/terminal/editor/)会在你输入命令时自动识别命令的各个部分，并对其进行语法高亮。

### 如何启用/禁用语法高亮

语法高亮默认启用，切换方式如下：

* 通过 [Command Palette](/terminal/command-palette/)，搜索 "Syntax Highlighting" 选项并点击（或按回车）以启用/禁用。
* 通过 **Settings** > **Features** > **Terminal Input**，切换 "Syntax highlighting for commands"。

## 什么是错误下划线

Warp 会高亮显示在[输入编辑器](/terminal/editor/)中输入的命令中的错误，例如当你输入的命令二进制文件不存在时。

:::caution
新安装的应用或新创建的别名在你打开新的 Warp 会话（新窗口、标签页或分屏）之前会触发错误下划线，即使你在当前会话中 `source` 了 RC 文件也不例外。
:::

### 如何访问错误下划线

启用错误下划线后，Warp 会自动用红色虚线下划线标记无效命令。

### 如何启用/禁用错误下划线

错误下划线默认启用，切换方式如下：

* 通过 [Command Palette](/terminal/command-palette/)，搜索 "Syntax Highlighting" 选项并点击（或按回车）以启用/禁用。
* 通过 **Settings** > **Features** > **Terminal Input**，切换 "Error underlining for commands"。
