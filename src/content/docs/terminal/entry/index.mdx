1. [命令纠错](/terminal/entry/command-corrections/) 会对之前运行的命令提供自动纠正建议，以捕捉拼写错误、遗漏的标志以及修复常规控制台错误。
2. [命令搜索](/terminal/entry/command-search/) 是一个三合一面板，可同时搜索命令历史、工作流、笔记本和 AI 命令搜索。
3. [命令历史](/terminal/entry/command-history/) 让 Warp 能够隔离每个 shell 会话的历史记录，方便访问之前运行过的命令。
4. [同步输入](/terminal/entry/synchronized-inputs/) 让你可以轻松在多个会话中同时运行相同的命令。
5. [YAML 工作流](/terminal/entry/yaml-workflows/) 让参数化、可搜索的命令在 Warp 中更易执行和共享。
