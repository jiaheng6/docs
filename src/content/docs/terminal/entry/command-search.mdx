命令搜索面板提供跨所有终端输入、已保存命令和[终端与 Agent 模式](/agent-platform/local-agents/interacting-with-agents/terminal-and-agent-modes/)对话历史的统一搜索。使用它可以快速查找和复用命令、工作流或过去的 Agent 交互记录。

![命令搜索面板](../../../../assets/terminal/command-search-panel.png)

:::note
你可以通过在 **Settings** > **Features** > **Workflows** 中关闭 "Show Global Workflows" 来定制命令搜索体验。禁用后，搜索将仅包含 YAML 和 Warp Drive 工作流。
:::

## 快速开始

1. 按 `CTRL-R` 打开命令搜索面板
2. 在输入框中输入搜索词
3. 按 `ENTER` 将选中的命令输入到 Warp 的输入编辑器中

## 搜索过滤器

在搜索词前加上以下任意前缀可以过滤搜索结果：

<table><thead><tr><th width="215.78436279296875">过滤器</th><th>快捷方式</th></tr></thead><tbody><tr><td>命令历史</td><td><code>history:</code>、<code>h:</code> 或 <code>H-TAB</code></td></tr><tr><td>提示词</td><td><code>prompts:</code>、<code>p:</code> 或 <code>P-TAB</code></td></tr><tr><td><a href="/agent-platform/local-agents/interacting-with-agents/">Agent Mode</a> 历史</td><td><code>ai_history:</code>、<code>a:</code> 或 <code>A-TAB</code></td></tr></tbody></table>

:::note
激活过滤器后，它会在搜索面板中以粗体和斜体显示。
:::

## 附加功能

* 你可以通过拖动右边缘横向展开菜单
* 面板支持模糊搜索，并按相关性对结果进行排序
