## 功能介绍

此功能基于开源项目 [nvdn/thefuck](https://github.com/nvbn/thefuck) 构建。以下是 Warp 团队通常认为命令纠错有用的一些示例：

* 拼写错误的命令
  * `gti checkout myBranchName` -> `git checkout myBranchName`
  * `cd ap/sorce/executtor` -> `cd app/source/executor`
* 缺少标志
  * `git push` -> `git push –set-upstream myBranchName`
* 添加权限
  * `./script` -> `chmod +x ./script && ./script`

## 如何访问

* 命令纠错默认启用。你可以通过 **Settings** > **Features** > **Terminal Input** > 切换 "Suggest corrected commands" 来禁用。
* 运行错误命令后，输入编辑器上方会出现一个显示纠正建议的面板。`点击`或按 `RIGHT` 方向键插入建议。
