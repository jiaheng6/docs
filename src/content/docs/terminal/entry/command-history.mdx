## 功能介绍

运行时，Warp 会隔离每个 shell 会话的历史记录。例如，如果你打开了两个分屏窗格，在一个窗格中创建的命令不会出现在另一个窗格的历史记录中。Warp 在关闭时会合并历史记录。

命令历史还提供丰富的信息，例如退出码、目录、线程、运行完成时间、上次运行时间等。

## 如何访问

* 在[输入编辑器](/terminal/editor/)中按 `UP` 方向键可调出历史记录，并根据输入进行前缀搜索。
* 按 `CTRL-R` 可打开[命令搜索](/terminal/entry/command-search/)面板，并开始搜索命令历史。在命令搜索面板中：
  * 开始输入，Warp 会自动使用模糊搜索进行过滤。使用模糊搜索过滤时，Warp 会加粗匹配的文本。
