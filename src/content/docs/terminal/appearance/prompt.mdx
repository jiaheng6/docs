Warp 支持两种提示符类型：**Warp 提示符**和 **Shell 提示符（PS1）**。

## 选择提示符类型

切换提示符类型：

1. 打开 **Settings** > **Appearance**。
2. 在 **Input** 下，将 **Input type** 设置为 **Warp** 或 **Shell (PS1)**。

使用 Warp 提示符时，你可以右键点击提示符区域，复制整个提示符、工作目录、当前 Git 分支、Git 未提交文件数量等信息。

使用 Shell 提示符时，你可以右键点击提示符区域复制整个提示符，或在会话中已运行的 Block 中选择提示符的任意部分。

## Warp 提示符

Warp 有一个原生提示符，显示上下文信息片段，包括当前工作目录、Git 分支、svn 状态、Kubernetes 上下文、pyenv、日期和时间等信息。当 **Input type** 设置为 **Warp** 时，Warp 提示符为默认设置。

要自定义 Warp 提示符显示的上下文信息片段：

1. 右键点击提示符区域，选择 **Edit prompt**。

2. 选择 **Warp Prompt**。
3. 拖放上下文信息片段以配置提示符显示的信息。

### Git 和 Subversion

Git 和 Subversion 上下文信息片段显示你当前所在的本地分支，以及未提交的已更改文件数量，包括已暂存或未暂存的新文件、修改文件和已删除文件。

### Kubernetes

Kubernetes 上下文信息片段在使用以下命令之一时显示相关信息：

`kubectl|helm|kubens|kubectx|oc|istioctl|kogito|k9s|helmfile|flux|fluxctl|stern|kubeseal|skaffold|kubent|kubecolor|cmctl|sparkctl|etcd|fubectl`

:::note
Warp 遵循 `KUBECONFIG` 环境变量。如果你的配置文件位置不是默认路径 `~/.kube/config`，请确保将其设置为你的首选路径。
:::

## Shell 提示符（PS1）

你可以通过配置 **PS1** 变量或安装受支持的 Shell 提示符插件来使用 Shell 提示符，而不是 Warp 提示符（请参阅 [Shell 提示符兼容性表格](/terminal/appearance/prompt/#shell-prompt-compatibility-table)）。

启用 Shell 提示符：

1. 打开 **Settings** > **Appearance**。
2. 在 **Input** 下，将 **Input type** 设置为 **Shell (PS1)**。
3. 在你 Shell 的 RC 文件中配置 PS1 变量，或安装受支持的提示符插件。

:::note
PS1 是 Shell 用于生成提示符的变量，代表主提示符字符串（"PS"的含义）——终端通常在输入新命令之前显示它。
:::

### 多行和右侧提示符

Shell 提示符支持 zsh 和 fish 中的多行或右侧提示符，但不支持 bash。但是，不能同时有多行右侧提示符，只能有多行左侧提示符。

:::note
如果你想在 Shell 提示符中添加新行，请根据你的 Shell 或提示符运行以下命令：

```sh
# Bash
echo -e '\nPS1="${PS1}"$'\''\\n'\''' >> ~/.bashrc

# Zsh
echo -e '\nPROMPT="${PROMPT}"$'\''\\n'\''' >> ~/.zshrc

# Fish
echo -e '\nfunctions --copy fish_prompt fish_prompt_orig; function fish_prompt; fish_prompt_orig; echo; end' >> ~/.config/fish/config.fish

# Powershell
$rawString = @'
$originalPrompt = Get-Item Function:\prompt
Set-Item -Path Function:\prompt_original -Value $originalPrompt
function prompt {
    "$(& prompt_original)`n"
}
'@
Add-Content -Path $PROFILE -Value "`n$rawString`n"

# Powerlevel10k
p10k configure

# Starship Prompt
echo '[line_break]\ndisabled = false' >> ~/.config/starship.toml
```
:::

## 已知不兼容项

如果你在使用提示符时遇到问题，请参阅以下内容或我们的[已知问题](/support-and-community/troubleshooting-and-support/known-issues/#configuring-and-debugging-your-rc-files)获取更多故障排除步骤。

### Starship

#### Starship 设置

某些 `~/.config/starship.toml` 设置已知会在 Warp 中导致错误。请用 `#` 注释或删除以下行以解决已知错误：

```
# Get editor completions based on the config schema
'' = 'https://starship.rs/config-schema.json'

# Disables the custom module
[custom]
disabled = false
```

对于 `fish` Shell，以及可选的 `bash|zsh`，通过在 `~/.config/starship.toml` 中添加以下内容来禁用 Starship 的多行提示符：

```
[line_break]
disabled = true
```

你可能还会看到与超时相关的错误。可以在 `~/.config/starship.toml` 中设置 `command_timeout` 变量来解决此问题。详情请参阅 [Starship 文档](https://starship.rs/config/#prompt)。

#### Starship + bash

如果你的[默认 Shell](/getting-started/supported-shells/#changing-what-shell-warp-uses) 是 `/bin/bash`，Starship 提示符可能无法正确渲染。作为[解决方案](https://github.com/warpdotdev/Warp/issues/3066#issuecomment-1548643121)，我们建议你升级 bash，用 `echo $(which bash)` 找到路径，然后在 **Settings** > **Features** > **Session** > **"Startup shell for new sessions"** 中填入该路径。

#### Starship + zsh

如果你想在 `zsh` 上恢复 Starship 提示符后的附加行，请在 `~/.zshrc` 文件底部添加以下内容：`PROMPT="${PROMPT}"$'\n'`

### Powerlevel10k

安装 Powerlevel10k（P10k）提示符时，我们建议你使用 [Meslo Nerd Font](https://github.com/romkatv/powerlevel10k/blob/master/font.md)。\
\
P10K 可能会将箭头分隔符显示为灰色而不是彩色。由于 Warp 的最低对比度设置，这些字符的颜色渲染为灰色。要[解决](https://github.com/warpdotdev/Warp/issues/2851#issuecomment-1605005256)此问题，请前往 **Settings** > **Appearance** > **Text** > **Enforce minimum contrast** 并将其设置为"Never"。

<figure>
![p10k 中灰色分隔符示例](../../../../assets/terminal/p10k-grey-arrow-prompt.png)
<figcaption>p10k 中灰色分隔符示例。</figcaption>
</figure>

Warp 支持 [p10k](https://github.com/romkatv/powerlevel10k#installation) 1.19.0 及以上版本。请确保安装了最新版本，并在安装/更新 p10k 后重启 Warp。然后按照[上述步骤](/terminal/appearance/prompt/#choosing-your-prompt-type)启用自定义提示符，即可正常使用。

:::note
Warp 仍不完全支持某些 p10k 功能，例如过渡提示符和渐变等视觉效果。
:::

### Spaceship

此提示符可能会导致 Warp 输入编辑器中的类型预测出现问题。作为[解决方案](https://github.com/warpdotdev/Warp/issues/1973#issuecomment-1340150521)，请运行 `echo "SPACESHIP_PROMPT_ASYNC=FALSE" >>! ~/.zshrc`。

### Prezto

尽管 Warp 支持 prezto 的提示符，但在 `.zpreztorc` 中启用 [prezto utility 模块](https://github.com/sorin-ionescu/prezto/blob/master/modules/utility/README.md) 不受支持，与许多其他[不兼容的自动补全插件](/support-and-community/troubleshooting-and-support/known-issues/#list-of-incompatible-tools)一样。

### 为 Warp 禁用不支持的提示符

我们建议使用 Warp 的默认提示符或安装受支持的工具，请参阅[兼容性表格](/terminal/appearance/prompt/#shell-prompt-compatibility-table)。你可以按如下方式为 Warp 禁用不支持的提示符：

```
if [[ $TERM_PROGRAM != "WarpTerminal" ]]; then
##### WHAT YOU WANT TO DISABLE FOR WARP - BELOW

    # Unsupported Custom Prompt Code

##### WHAT YOU WANT TO DISABLE FOR WARP - ABOVE
fi
```

#### iTerm2

iTerm2 的 Shell 集成会破坏 Warp，启用此集成后你的自定义提示符将无法显示。如果你之前使用的是 iTerm2，请检查你的 dotfiles。我们建议按如下方式为 Warp 禁用该集成：

```
if [[ $TERM_PROGRAM != "WarpTerminal" ]]; then
##### WHAT YOU WANT TO DISABLE FOR WARP - BELOW

test -e "${HOME}/.iterm2_shell_integration.zsh" && source "${HOME}/.iterm2_shell_integration.zsh"

##### WHAT YOU WANT TO DISABLE FOR WARP - ABOVE
fi
```
