## 如何访问

* 可以通过前往 **Settings** > **Appearance** > **Input** 来配置输入位置。
* 也可以从 [Command Palette](/terminal/command-palette/) 中选择和设置模式。

:::note
输入位置的更改会立即生效，并应用于所有打开的面板。
:::

### 相关命令

<Tabs>
  <TabItem label="macOS">
    * `CMD-K` 将清除整个输入/输出 Block 列表，获得干净的视图
    * `CTRL-L` 将把输入/输出 Block 列表移到视图之外并超出滚动范围，从而获得干净的视图，同时方便查看过去的命令
    * 对于较长的 Block，可以按 `SHIFT-CMD-UP`/`SHIFT-CMD-DOWN` 滚动到所选 Block 的顶部/底部。
  </TabItem>
  <TabItem label="Windows">
    * `CTRL-SHIFT-K` 将清除整个输入/输出 Block 列表，获得干净的视图
    * `CTRL-L` 将把输入/输出 Block 列表移到视图之外并超出滚动范围，从而获得清晰的视图，同时方便查看过去的命令
    * 对于较长的 Block，可以按 `CTRL-SHIFT-UP`/`CTRL-SHIFT-DOWN` 滚动到所选 Block 的顶部/底部。
  </TabItem>
  <TabItem label="Linux">
    * `CTRL-SHIFT-K` 将清除整个输入/输出 Block 列表，获得干净的视图
    * `CTRL-L` 将把输入/输出 Block 列表移到视图之外并超出滚动范围，从而获得清晰的视图，同时方便查看过去的命令
    * 对于较长的 Block，可以按 `CTRL-SHIFT-UP`/`CTRL-SHIFT-DOWN` 滚动到所选 Block 的顶部/底部。
  </TabItem>
</Tabs>
