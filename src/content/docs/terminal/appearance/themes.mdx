### 主题选择器

主题选择器可通过以下方式访问：

1. 前往 **Settings** > **Appearance**。
2. 点击自定义主题（阴影）框。
3. 选择主题后，Warp 的外观将相应更新。
4. 按勾选标记保存选择，或按 X 撤销。

:::note
主题设置会持久保存，即 Warp 在下次会话中将以相同的设置启动。
:::

### 主题创建器

基于背景图片自动创建新主题。

1. 前往 **Settings** > **Appearance** > **Themes**，或在 [Command Palette](/terminal/command-palette/) 中搜索"Open theme picker"。
2. 点击主题选择器中的 **+** 按钮。
3. 上传图片并选择背景颜色。
4. 点击"Create Theme"保存并应用新主题。

### OS 主题同步

Warp 支持将主题与操作系统的浅色和深色主题同步。启用此功能：

1. 打开 **Settings** > **Appearance** 对话框。
2. 点击"Sync with OS"开关。
3. 然后你可以分别为操作系统处于浅色模式和深色模式时选择特定主题。
