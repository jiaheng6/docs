## 如何使用

### 窗口大小

前往 **Settings** > **Appearance** > **Window** 访问大小设置。

* 启用"Open new windows with custom size"，然后配置你首选的列数和行数。

:::note
如果启用了[会话恢复](/terminal/sessions/session-restoration/)，Warp 在退出应用时将恢复最后关闭的窗口大小。请确保自定义大小的窗口是最后关闭的窗口，或者禁用会话恢复，以确保 Warp 以自定义大小的窗口启动。
:::

### 窗口透明度

前往 **Settings** > **Appearance** > **Window** 进行设置。

* 滑块支持设置 `1` 到 `100` 之间的透明度值，其中 `100` 表示完全不透明（实心）。

### 窗口模糊

降低透明度（将滑块移至低于 `100` 的值）后，你还可以模糊背景。

* 在 macOS 上，通过模糊滑块实现。增大滑块值会增大应用于背景图片的模糊半径。
* 在 Windows 上，通过切换亚克力背景纹理的开关实现。

:::caution
在 macOS 上，较大的模糊半径可能影响性能，尤其是在 Retina 显示屏上。

在 Linux 上，不支持窗口模糊。

在 Windows 上，某些显卡驱动程序可能不支持渲染透明或半透明窗口。请参阅下方的故障排除提示。
:::

### Windows 上透明度故障排除

:::note
目前，Warp 在 Windows 上的窗口透明度在以下情况下**无法正常工作**：

* 使用 DirectX 12 作为渲染后端时
* 在 NVIDIA 控制面板 > 管理 3D 设置中，"Vulkan/OpenGL 呈现方法"选择了"自动"或"首选分层"时，无论使用哪种渲染后端，搭配 Nvidia GPU 均无效
:::

某些显卡驱动程序和渲染后端可能不支持渲染透明窗口。

你可以在 Settings 菜单的 `Features` > `System` > `Preferred graphics backend` 下选择 Vulkan 或 OpenGL 图形后端来渲染新的 Warp 窗口。

你也可以在 `Features` > `System` > `Prefer rendering new windows with integrated GPU (low power)` 下选择使用集成 GPU 渲染新的 Warp 窗口。
