## 紧凑模式

Warp 提供启用紧凑模式的选项，该模式会压缩 [Blocks](/terminal/blocks/) 之间的间距，使更多内容可以同时显示。

### 如何启用紧凑模式

紧凑模式默认关闭，可通过以下方式切换：

* 前往 **Settings** > **Appearance** > **Blocks** > **Compact Mode**。
* 使用 [Command Palette](/terminal/command-palette/)，然后搜索"Compact mode"进行切换。

:::note
Warp 在以后的会话中将以相同的紧凑设置启动。
:::

## Block 分隔线

Warp [Blocks](/terminal/blocks/) 之间由水平线分隔，用于区分各个命令的输入和输出，在会话中运行的不同命令之间形成视觉分隔。

### 如何切换 Block 分隔线

Block 分隔线默认启用，可通过以下方式切换：

* 前往 **Settings** > **Appearance** > **Blocks** > **Show block dividers**。
* 使用 [Command Palette](/terminal/command-palette/)，然后搜索"Block Dividers"。
