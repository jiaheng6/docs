在系统中安装新字体后，需要重启 Warp 才能在选项列表中显示该字体。你可能还需要勾选"View all available system fonts"才能看到新字体。
:::

## 如何使用

### 文本和字体

前往 **Settings** > **Appearance** > **Text** 进行设置。

你可以自定义：

* 字体类型
* 字体粗细
* 字体大小
* 行高
* 使用细笔画
  * 默认设置可防止文本在低 DPI 显示屏上模糊。

:::caution
在 Linux 上，Warp 不支持"Use thin stroke"功能。
:::

* 强制最低对比度
  * 默认设置会调整命名颜色以符合无障碍标准。
* 在终端中显示连字

:::note
启用连字可能会降低性能。Warp 的默认字体 Hack 尚不支持连字。我们推荐使用支持连字的字体（例如 [Fira Code](https://github.com/tonsky/FiraCode)）作为临时替代方案。
:::

### 光标

前往 **Settings** > **Appearance** > **Cursor** 进行设置。

你可以自定义：

* 选择光标类型：竖线（Bar）、块状（Block）或下划线（Underline）。
* 切换光标闪烁，或从 [Command Palette](/terminal/command-palette/) 中输入"Cursor blink"并切换该设置。

:::note
使用 [Vim 键绑定](/terminal/editor/vim/)（vim 模式）时，光标类型偏好设置将被禁用。
:::
