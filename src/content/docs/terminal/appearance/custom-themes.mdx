## Warp 的自定义主题仓库

我们在 GitHub 上托管了一个[主题仓库](https://github.com/warpdotdev/themes)。

每个主题在 README 中都有预览图。

"standard"主题和"base16"主题的主要区别在于："standard"主题遵循典型的颜色设置，而"base16"主题遵循 [@chriskempson](https://github.com/chriskempson/base16) 提出的框架。

从该仓库安装主题有两种方式：

1. 下载单个文件，然后按照下方步骤操作。
2. 根据你的操作系统，将整个仓库克隆到对应位置：

<Tabs>
  <TabItem label="macOS">
    ```bash
    mkdir -p $HOME/.warp
    cd $HOME/.warp/
    git clone https://github.com/warpdotdev/themes.git
    ```
  </TabItem>
  <TabItem label="Windows">
    ```powershell
    New-Item -Path "$env:APPDATA\warp\Warp\data\" -ItemType Directory
    Set-Location -Path $env:APPDATA\warp\Warp\data\
    git clone https://github.com/warpdotdev/themes.git
    ```
  </TabItem>
  <TabItem label="Linux">
    ```bash
    mkdir -p ${XDG_DATA_HOME:-$HOME/.local/share}/warp-terminal
    cd ${XDG_DATA_HOME:-$HOME/.local/share}/warp-terminal/
    git clone https://github.com/warpdotdev/themes.git
    ```
  </TabItem>
</Tabs>

## 如何在 Warp 中使用自定义主题？

1. 首先，创建以下目录：

<Tabs>
  <TabItem label="macOS">
    ```bash
    mkdir -p $HOME/.warp/themes/
    ```
  </TabItem>
  <TabItem label="Windows">
    ```powershell
    New-Item -Path "$env:APPDATA\warp\Warp\data\themes\" -ItemType Directory
    ```
  </TabItem>
  <TabItem label="Linux">
    ```bash
    mkdir -p ${XDG_DATA_HOME:-$HOME/.local/share}/warp-terminal/themes/
    ```
  </TabItem>
</Tabs>

:::note
Warp 最初可能需要几分钟时间才能发现新的主题目录。你可以等待或重启 Warp。之后，对目录的所有更改将在几秒内生效。
:::

2. 将新的自定义主题 yaml 文件添加到此目录：

```bash
cp ~/Downloads/my_awesome_theme.yaml {{path_to_your_themes_directory_from_step1}}
```

你的新主题现在应该出现在可用主题列表中。

## 手动创建自定义主题

Warp 支持使用 .yaml 文件创建自定义主题。

格式可能会有所变化，但我们会尽力避免破坏性更改并保持向前兼容性。我们也计划支持直接在 Warp 内分享和创建自定义主题。

Warp 自定义主题的 `.yaml` 结构如下：

```yaml
name: Custom Theme # Name for the theme
accent: '#268bd2' # Accent color for UI elements
cursor: '#95D886' # Input cursor color (optional; defaults to accent color if omitted)
background: '#002b36' # Terminal background color
foreground: '#839496' # The foreground color
details: darker # Whether the theme is lighter or darker
terminal_colors: # Ansi escape colors
  bright:
    black: '#002b36'
    blue: '#839496'
    cyan: '#93a1a1'
    green: '#586e75'
    magenta: '#6c71c4'
    red: '#cb4b16'
    white: '#fdf6e3'
    yellow: '#657b83'
  normal:
    black: '#073642'
    blue: '#268bd2'
    cyan: '#2aa198'
    green: '#859900'
    magenta: '#d33682'
    red: '#dc322f'
    white: '#eee8d5'
    yellow: '#b58900'
```

:::note
每种颜色均以十六进制表示，且必须以 `#` 开头。
:::

* `name`：主题名称，将显示在主题选择器中。
* `accent`：用于 Warp 界面高亮的颜色
* `cursor`：输入光标颜色（可选；省略时默认使用强调色）
* `background`：背景颜色
* `foreground`：前景颜色
* `details`：用于细节选项的颜色
  * `darker`：深色主题使用的颜色
  * `lighter`：浅色主题使用的颜色
* `terminal_colors`：普通色和高亮色的集合（共 16 种），与其他终端主题（ANSI 颜色）相同

## 自动创建自定义主题

基于背景图片自动创建新主题。点击主题选择器中的 **+** 按钮，路径为 **Settings** > **Appearance** > **Themes**，或在 [Command Palette](/terminal/command-palette/) 中搜索 `Open Theme Picker`。

## 浏览主题并使用主题创建器

浏览 Warp 的[主题仓库](https://github.com/warpdotdev/themes)获取现成主题，或使用应用内主题创建器为你的自定义主题生成合适的 RGB 值。创建 YAML 文件后，你可以编辑该文件以添加背景图片或渐变效果。

## 背景图片和渐变

要添加背景图片，可以使用以下属性：`background_image:`，并设置你想用作背景的图片名称。

:::note
注意：Warp 目前仅支持 _.jpg_ 格式的图片：

* `.jpeg`
* `.jpg`
* `.JPEG`
:::

`.yaml` 配置示例如下：

```yaml
name: Custom Theme
accent: '#268bd2'
cursor: '#95D886'
background: '#002b36'
details: darker
foreground: '#839496'

############################################################### SEE BELOW
background_image:
  # the path is relative to ~/.warp/themes/
  # the full path to the picture is: ~/.warp/themes/warp.jpg
  path: warp.jpg
  # the opacity value is required and can range from 0-100
  opacity: 60
############################################################### SEE ABOVE

terminal_colors:
  bright:
    black: '#002b36'
    blue: '#839496'
    cyan: '#93a1a1'
    green: '#586e75'
    magenta: '#6c71c4'
    red: '#cb4b16'
    white: '#fdf6e3'
    yellow: '#657b83'
  normal:
    black: '#073642'
    blue: '#268bd2'
    cyan: '#2aa198'
    green: '#859900'
    magenta: '#d33682'
    red: '#dc322f'
    white: '#eee8d5'
    yellow: '#b58900'
```

要设置渐变，在 accent 下创建一个子级，包含两个键值对：

* "left"（左）和"right"（右），或
* "top"（上）和"bottom"（下）。

```yaml
accent:
  top: '#abcdef'
  bottom: '#fedcba'
```

```yaml
accent:
   left: '#abcdef'
   right: '#fedcba'
```

Warp 还支持为背景设置渐变。

```yaml
# accent has a gradient
accent:
  left: '#474747'
  right: '#ffffff'
# background has a gradient
background:
  top: '#474747'
  bottom: '#ffffff'
```

### 贡献

非常欢迎向此仓库贡献！

1. Fork 该项目
2. 使用 `git checkout -b theme/AwesomeTheme` 创建你的分支
3. 重新生成缩略图
4. 提交并发起 pull request

运行以下脚本来生成缩略图。

```bash
# Assuming you're adding the theme to the `standard` directory:
python3 ./scripts/gen_theme_previews.py standard
```

:::note
注意：我们无法接受包含自定义背景图片的 pull request，原因如下：

* 许可限制
* 尽量保持仓库的二进制体积尽可能小（仅保留 yaml 文件）

如果你的主题有预期的自定义背景图片，请在 yaml 文件中添加注释，附上图片的下载链接。
:::
