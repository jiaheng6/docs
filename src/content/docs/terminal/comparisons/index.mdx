Warp 是一款使用 Rust 构建、支持 GPU 渲染、具备 Agent 支持和代码编辑器式输入的现代终端。本节展示 Warp 在原始性能和功能覆盖方面与其他流行终端的对比情况。

## Warp 的不同之处

* **AGPL v3 开源** — Warp 的客户端代码位于 [`warpdotdev/warp`](https://github.com/warpdotdev/warp)。你可以阅读代码、从源码构建并贡献代码。参见 [贡献 Warp](/support-and-community/community/contributing/) 了解流程。
* **内置 Agent** — Warp 内置了 Warp Agent（由 Oz 驱动），并支持来自同一终端的第三方 CLI Agent，如 Claude Code、Codex 和 Gemini CLI。
* **现代编辑体验** — 光标定位、多行输入、基于 Block 的输出和集成代码审查的工作方式更像文本编辑器，而非传统终端模拟器。
* **跨平台 Rust 核心** — Warp 在 macOS、Linux 和 Windows 上均可运行，共享同一个 Rust + GPU 渲染代码库。
