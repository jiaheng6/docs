## 基准测试中选择的终端应用

我们选择了另外 4 款终端模拟器应用与 Warp 进行基准对比，选择依据是它们的流行程度以及使用的语言和设计理念。以下是参与对比的应用列表，并说明了选择原因：

* Terminal.app - macOS 上默认的终端应用；
* ITerm2 - macOS 用户最常用的终端模拟器之一；
* Alacritty & WezTerm - 这两款终端均使用 Rust 编写，以速度和整体性能著称，这也是 Warp 的目标。

### 对比中使用的版本和设置

| Terminal     | Version                        | Terminal size (cols / rows, window is identical pixel-wise) |
| ------------ | ------------------------------ | ----------------------------------------------------------- |
| Warp         | v0.2022.04.01.01.37.stable\_03 | 208 cols / 54 rows                                          |
| Terminal.app | Version 2.11 (440)             | 188 cols / 72 rows                                          |
| iTerm2       | Build 3.4.15                   | 211 cols / 78 rows                                          |
| Alacritty    | alacritty 0.10.1 (2844606)     | 286 cols / 102 rows                                         |
| Wezterm      | 20220319-142410-0fcdea07       | 243 cols / 80 rows                                          |

### 关于基准测试

我们提供了每项基准测试所用源码的链接，方便你在其他终端应用上自行复现测试。请注意，这些基准测试并不全面。比较不同终端模拟器并非易事——目前我们关注的是各应用在处理大量输入和/或输出时的表现。

理想情况下，基准测试还应涵盖延迟（按键到字符显示在屏幕上的时间，以及用户输入与 shell 通信之间的延迟）。我们可能会在未来加入相关测试。
